1. Premiers pas

  1. Installez HEXIS_PAD.apk sur un téléphone ou une tablette Android (autorisez «l'installation depuis des sources inconnues» pour le navigateur/les fichiers).
  2. La première fois, le code de licence est demandé (format PAD-XXXX-XXXX-XXXX). Saisissez-le et appuyez sur Activer — Internet n'est nécessaire que cette fois-là. Voir Licence.
  3. Ouverture → accordez les autorisations Bluetooth, position et appareil photo quand elles sont demandées.
  4. Connexion au récepteur et au NTRIP la première fois : voir Première connexion pas à pas.
  5. L'application s'ouvre avec un projet. Menu → Projets pour un nouveau projet, renommer, changer.
  6. La barre supérieure affiche : solution (FIX vert, FLOAT orange, SINGLE/DGPS rouge), sH / sV (m, 1 sigma), satellites, PDOP, âge des corrections, indicateurs QC et NTRIP. Un appui sur la barre → état GNSS détaillé.
Thèmes d'affichage : ☀ Soleil (contraste maximal en plein soleil) et NEO sombre (faible luminosité). Menu → Réglages.

Première connexion pas à pas : récepteur et NTRIP

Ces étapes se font une seule fois. Ensuite l'application mémorise le récepteur et le réseau : vous ouvrez l'application, allumez le récepteur, et tout se connecte seul.

Avant de commencer, ayez sous la main : le récepteur chargé, le téléphone avec les données mobiles (4G/5G) activées, et les identifiants de l'abonnement NTRIP : caster host, port, utilisateur et mot de passe. Ils sont fournis par le réseau de stations permanentes auquel vous êtes abonné.

A. Connexion du récepteur en Bluetooth

  1. Allumez le récepteur et attendez que le voyant Bluetooth s'allume.
  2. Appairage dans Android : Paramètres du téléphone → Bluetooth → Associer un nouvel appareil → choisissez le récepteur. Son nom est en général le numéro de série (S/N) de l'étiquette sous le récepteur. Si un code est demandé : 1234 ou 0000.
    Plus rapide : la première fois, l'application affiche l'écran «Première connexion du récepteur». Le bouton «Appairer le récepteur (Bluetooth)» ouvre directement les réglages Bluetooth. Si le récepteur a le NFC, il suffit de poser le téléphone dessus.
  3. Revenez dans HEXIS PAD. Il trouve le récepteur et se connecte seul. Sinon : Accueil → Récepteur & RTK → Connecter le récepteur → Bluetooth → choisissez le récepteur → Connexion.
  4. La première fois, Android demande l'autorisation «Appareils à proximité». Appuyez sur Autoriser.
  5. Contrôle : la barre supérieure affiche une solution SINGLE ou DGPS (rouge) et le nombre de satellites. Le récepteur envoie la position. Le RTK arrive avec le NTRIP (étape C).

B. Connexion via le Wi-Fi du récepteur (si le Bluetooth n'envoie pas de position)

  1. Accueil → Récepteur & RTK → Connexion via le Wi-Fi du récepteur.
  2. Choisissez le constructeur, puis le récepteur dans la liste.
  3. Android ouvre la fenêtre «Recherche d'appareils». Choisissez le réseau Wi-Fi du récepteur → Connexion. Le Wi-Fi du récepteur est utilisé uniquement par l'application, tandis qu'Internet pour le NTRIP continue via les données mobiles.
  4. Dès lors, quand le récepteur s'allume, la carte Récepteur de l'accueil affiche «Récepteur trouvé · appuyez pour connecter». Un appui et il se connecte. La fenêtre «Recherche d'appareils» d'Android ne s'ouvre que si vous la demandez, jamais d'elle-même. Si le téléphone est déjà connecté au Wi-Fi du récepteur, la connexion se fait automatiquement, sans fenêtre.

C. NTRIP : corrections RTK d'un réseau de stations permanentes

  1. Accueil → Récepteur & RTK → NTRIP / RTK.
  2. Réseau de stations permanentes : choisissez le réseau de votre abonnement (p. ex. HEPOS (Cadastre hellénique)). Pour un autre réseau, choisissez «Autre réseau / mon propre caster» et saisissez Caster host et Port (généralement 2101).
  3. Saisissez l'Utilisateur et le Mot de passe de l'abonnement.
  4. Appuyez sur Liste : les mountpoints du réseau sont récupérés. Choisissez celui fourni par le réseau, généralement un VRS au format MSM.
  5. Laissez coché «Envoi GGA (nécessaire pour VRS / réseaux)». Cochez aussi «Démarrage automatique à la connexion du récepteur», pour qu'il démarre seul à chaque fois.
  6. 💾 Profil → enregistrez les paramètres sous un nom. Si vous avez deux réseaux ou comptes, vous basculez d'un appui.
  7. Appuyez sur Démarrer. L'indicateur NTRIP de la barre supérieure devient vert quand les corrections arrivent. En quelques secondes, jusqu'à 1–2 minutes avec une mauvaise visibilité, la solution passe de FLOAT (orange) à FIX (vert).

D. Contrôle avant le travail

  • Hauteur d'antenne : saisissez la hauteur de la canne dans le champ Hauteur d'antenne en bas de l'écran. Si le récepteur a un offset de centre de phase, il se règle une fois dans Connecter le récepteur. Une erreur ici fausse toutes les altitudes.
  • Système de coordonnées : Accueil → Récepteur & RTK → Système de coordonnées → GGRS87 (HEPOS). Ce choix applique la grille de transformation officielle, en planimétrie comme en altimétrie.
  • FIX avec de faibles sH / sV dans la barre supérieure et indicateur QC vert.
  • Mesurez un point connu (p. ex. point géodésique ou point de coordonnées et altitude connues) et comparez, avant tout lever ou implantation.

Écran d'accueil, carte et colonne d'outils

Écran d'accueil (bouton ⌂ dans la colonne) : en haut, le Projet et le Récepteur, avec un point vert, orange ou rouge pour FIX, FLOAT ou sans solution. En dessous se trouvent six catégories, toutes du même bleu :

  • Lever : démarrer le lever, continu, static, point par laser, point inaccessible, commandes vocales.
  • Implantation : points, ligne, dalles/pentes, équerrage, grille.
  • Calculs : tous les outils COGO, distance/azimut, surface, intersection de droites, pente, calage local.
  • Fichiers & projets : import, points, coller, export/e-mail, projets.
  • Récepteur & RTK : connexion du récepteur, NTRIP, base/rover, IMU/bulle, laser, système de coordonnées.
  • Réglages : réglages, outils de la colonne, mode d'emploi.

Quand vous touchez une catégorie, vous ne voyez que ses options. La première, la principale, est le grand bouton coloré. Avec ‹ Retour, ou le bouton retour du téléphone, vous revenez aux catégories. Le bouton Carte en haut à droite mène directement à la carte.

Carte en plein écran : la colonne d'outils est repliée à gauche, pour que la carte occupe toute la largeur. Elle s'ouvre d'un appui ou d'un glissement depuis le bord gauche de l'écran (languette bleue ›), et se ferme dès que vous choisissez un outil, touchez la carte, ou d'elle-même après quelques secondes. Ses outils s'ajoutent et se retirent depuis «Outils de la colonne». Pour la garder ouverte en permanence : Réglages → Écran → Colonne d'outils → «Toujours ouverte». En haut s'affichent FIX, H/V, satellites, Age, QC et NTRIP, et en bas les coordonnées de la position.

2. Connexion du récepteur

  1. Appairez le récepteur depuis les réglages Bluetooth d'Android.
  2. Menu → Connecter le récepteur → Bluetooth, choisissez l'appareil → Connexion.
  3. Autres options : Wi-Fi / TCP (IP et port du récepteur), GPS du téléphone (orientation uniquement) ou Simulateur (formation — appui long sur la carte = «marchez là-bas»).

Tout récepteur NMEA 0183 est pris en charge. Le GGA est obligatoire ; le GST fournit les précisions sH/sV et le GSA le PDOP. Si le récepteur ne les envoie pas, saisissez une commande dans le champ «Commande d'initialisation» ou utilisez Base / Rover → Commandes rover.

Connexion automatique — sans réglages

  • Première fois : s'il n'y a pas de récepteur, l'écran «Première connexion du récepteur» apparaît. Allumez le récepteur, appuyez sur «Appairer le récepteur» et choisissez-le dans la liste Bluetooth. Si le récepteur a le NFC, posez le téléphone dessus. Revenez : l'application le trouve et le connecte d'elle-même.
  • Les fois suivantes : ouvrez l'application et allumez le récepteur, dans n'importe quel ordre. L'application se connecte seule, et si le récepteur est encore éteint elle réessaie toutes les quelques secondes. Ensuite le NTRIP démarre seul aussi, s'il est configuré.
  • Récepteur qui n'envoie pas de NMEA : l'application lui envoie automatiquement des commandes d'activation. Elle lit aussi la position directement depuis les protocoles publiés de la plupart des récepteurs (Unicore, NovAtel, u-blox, messages BESTPOS/BESTNAV, NAV-PVT). Dans ce cas, le message «Protocole du récepteur détecté» s'affiche.
  • Récepteurs avec Wi-Fi (Singular XYZ, CHC, South, Stonex, Hi-Target, Emlid) : la voie la plus stable est le Wi-Fi du récepteur. Récepteur → «📶 Connexion via le Wi-Fi du récepteur» → constructeur → le récepteur dans la liste. L'application se connecte au Wi-Fi du récepteur pour elle seule (les données mobiles restent pour le NTRIP), trouve seule le port qui fournit la position et se connecte ensuite automatiquement. Quand le récepteur est éteint, l'application vérifie discrètement en arrière-plan si son Wi-Fi est apparu et se connecte d'elle-même dès qu'il s'allume — sans fenêtres. Sur les récepteurs qui ne sortent pas de NMEA en configuration d'usine (p. ex. Singular X1 Lite), la page du récepteur s'ouvre une fois pour activer la sortie TCP NMEA-0183 (port 9000, GGA+GST+GSA, 1 Hz) — cela ne touche ni le Bluetooth ni le logiciel du constructeur. Quand le récepteur est allumé à proximité, la carte «Récepteur» affiche «Récepteur trouvé · appuyez pour connecter». La fenêtre «Recherche d'appareils» d'Android ne s'ouvre que si vous appuyez.
  • Si un récepteur n'envoie qu'un protocole chiffré du constructeur, la sortie NMEA s'active une fois depuis la page Wi-Fi du récepteur ou depuis son application. Avec «🔎 Échantillon de données du récepteur», vous pouvez envoyer ce que reçoit l'application, pour que la prise en charge soit ajoutée.
  • 🧪 Capturer le Bluetooth d'une autre application : si le récepteur n'envoie la position qu'au logiciel du constructeur, dans la fenêtre Connecter le récepteur appuyez sur «🧪 Capture Bluetooth», suivez les 4 étapes (Options pour les développeurs → «Journal HCI Bluetooth», Démarrer, connexion avec le logiciel du constructeur, Arrêter & envoyer) et envoyez-nous le fichier. Si le compteur reste à 0 kB, appuyez sur «🔍 Trouver & envoyer le fichier système» : l'application trouve seule le fichier de capture d'Android (btsnoop_hci.log) et l'envoie. La prise en charge du récepteur est ajoutée une fois pour tous les utilisateurs ; rien n'est modifié sur le récepteur ni sur l'autre logiciel.
  • «Déconnecter» arrête la reconnexion automatique jusqu'à ce que vous appuyiez à nouveau sur «Connexion».

Le récepteur n'apparaît pas dans la liste ? Dans la fenêtre Connecter le récepteur, appuyez sur ⚙ Réglages Bluetooth → Associer un nouvel appareil, et choisissez le récepteur. Son nom est généralement le numéro de série (S/N) de l'étiquette sous le récepteur, p. ex. «2124A0176». Revenez : la liste se met à jour d'elle-même. Il existe aussi le bouton «↻ Actualiser la liste». Les récepteurs GNSS probables apparaissent en premier avec ★, tandis qu'enceintes, voitures et écouteurs vont à la fin.

3. NTRIP (réseau de stations permanentes)

Se connecte à tout réseau NTRIP : HEPOS, URANUS, CivilPOS, HxGN SmartNet, JGC NET ou votre propre caster. Les identifiants de connexion sont fournis par le réseau avec l'abonnement.

  1. Menu → NTRIP / RTK : caster host, port (généralement 2101), utilisateur, mot de passe.
  2. Liste → récupère les mountpoints du caster. Choisissez celui qui convient (p. ex. VRS / MSM).
  3. Gardez actif «Envoi GGA» (nécessaire pour le VRS) → Démarrer.
  4. L'indicateur NTRIP devient vert quand les données arrivent. Les corrections sont transmises au récepteur via Bluetooth. En cas de coupure réseau, la reconnexion est automatique.
💾 Profil : enregistrez chaque réseau/compte pour basculer rapidement. «Démarrage automatique» = démarre seul à la connexion du récepteur.

4. Base / Rover et changement de base

Constructeur du récepteur

Menu → Base / Rover : choisissez la marque (CHC, South, Stonex, Hi-Target, ComNav, Singular XYZ, Kolida, Ruide, Tersus, SatLab, FOIF, Emlid, ArduSimple, Septentrio, Leica, GeoMax, Trimble, Spectra, Topcon, Sokkia). La famille de commandes de la carte électronique est proposée ; changez-la si votre modèle en utilise une autre.

FamilleCe que fait HEXIS PAD
Unicore, NovAtel/ComNav, SeptentrioInstalle la base (point connu ou «ici»), active la sortie RTCM3 sur le port radio, configure le rover et la sortie NMEA.
u-blox (Emlid etc.)Configuration depuis le panneau du constructeur ; HEXIS PAD fonctionne comme rover, NTRIP, lever, implantation.

Toutes les commandes s'affichent avant l'envoi — vérifiez-les avec le manuel du récepteur (surtout si la hauteur de base est ellipsoïdale ou orthométrique).

Nouvelle base

  1. ＋ Nouvelle base → Sur un point connu (choisissez un point) ou Position autonome «ici».
  2. Hauteur d'antenne de la base, port RTCM, ondulation du géoïde N.
  3. Commandes vers la base… → vérification → Envoyer (avec connexion Bluetooth à la base).
  4. Définir comme base active : chaque nouveau point est «lié» à cette base.

Translation de base

Si la base a été installée sur une position autonome/erronée : ouvrez la base dans la liste → indiquez la «position utilisée» et la «position correcte» → Appliquer la translation. Tous les points de la base sont translatés de dX/dY/dZ et c'est noté dans leur remarque.

5. Lever (Survey)

  1. Nom du point (incrémenté automatiquement), code (codes récents sous forme de boutons), hauteur d'antenne (canne + centre de phase).
  2. Durée : secondes (1, 2, 3, 5, 10, 15, 30 s, 1 ou 3 minutes) ou époques ; «Autre…» pour toute valeur. Époque = une solution de position du récepteur (à 1 Hz, 1 époque ≈ 1 s). La moyenne de toutes est calculée. FIX uniquement : les époques FLOAT sont rejetées.
  3. Attente en FIX (Réglages, par défaut 10 s) : la mesure ne commence que lorsque la solution reste FIX pendant ce nombre de secondes consécutives ; le bouton affiche «⏳ FIX 4/10 s».
  4. Dès que le point est enregistré, le bouton devient brièvement vert «✓ nom» (avec un son) puis revient, prêt pour la mesure suivante.
  5. Sons (Réglages → Sons, avec volume et test) : son d'enregistrement de point, son montant quand la solution passe en FIX, son grave et vibration quand le FIX est perdu.
  6. ● MESURER → un contrôle qualité est effectué (section 6). Un nouvel appui pendant la mesure = annulation.
  7. Ligne avec code : les points successifs de même code sont reliés en ligne (exportée en DXF).
  8. ⌖ Offset : point par distance + azimut (manuel ou depuis le laser).
  9. Mesure avec un nom qui existe déjà → comparaison de mesures indépendantes et option «Enregistrer comme contrôle».

Lever continu

Accueil → ⟳ Lever continu (ou outil ⟳ dans la colonne). Choisissez par distance (p. ex. tous les 1 m) ou par temps (p. ex. toutes les 2 s), le code, «Uniquement en FIX» et le sH maximal. Les points sont enregistrés automatiquement pendant que vous marchez et les noms s'incrémentent seuls. Sur la carte apparaît la barre «⟳ Continu · N points» avec le bouton ■ Arrêter. Si la solution n'est pas FIX ou si le sH dépasse la limite, la barre en indique la raison en jaune et aucun point n'est enregistré.

Static

Accueil → ◷ Static. Indiquez le point, le code, la hauteur d'antenne et la durée (5 minutes à 2 heures, ou «Jusqu'à ce que je l'arrête»). Le récepteur reste immobile et l'application :

  • conserve une solution par seconde et calcule la moyenne, sH et sV. Elle n'utilise que les solutions FIX quand il y en a. S'il n'y a aucun FIX, le point est marqué «SANS FIX».
  • enregistre toutes les données du récepteur dans le fichier Documents/HEXIS PAD/Static/<projet>_<point>_<date>.gnss pour post-traitement. Pour le traitement au bureau, le récepteur doit envoyer des observations brutes (RTCM3 MSM ou le format du constructeur).
  • à la fin, affiche le résultat et le bouton «Partager / envoyer le fichier par e-mail».

En appuyant à nouveau sur ◷ pendant l'enregistrement, vous voyez les statistiques en direct et pouvez terminer plus tôt.

Dessin de ligne point à point

Dans Survey, appuyez sur ✎ Dessin et dans le groupe Draw lines choisissez Line (segments droits indépendants), Polyline (ligne continue), Spline (courbe lisse passant par les points) ou Polygon (polygone fermé). Chaque bouton a une icône montrant la forme. Dès lors, chaque point mesuré s'ajoute à la ligne — une barre verte au-dessus de la carte indique le type et le nombre de points. Vous pouvez partir du dernier point mesuré. Dans la barre : ↶ retire le dernier point de la ligne (le point reste), ✕ annule la ligne (tous les points restent), ✓ Terminer la termine. À l'export DXF, les lignes sortent en LINE / POLYLINE / polyline dense pour la spline, sur le calque HP_<code>.

Hauteur d'antenne = canne + offset du récepteur

Dans le champ de Survey, saisissez uniquement la hauteur de la canne. L'offset d'antenne (du point de référence ARP au centre de phase, p. ex. 0.068 m pour Singular X1 Lite / L1) s'ajoute automatiquement quand le récepteur est reconnu, ou se règle dans Réglages → «Offset d'antenne du récepteur». L'étiquette du champ affiche «Canne (+0.068)» et les propriétés du point enregistrent les deux valeurs.

Erreur de position sans GST

Si le récepteur n'envoie pas de GST (p. ex. Singular via Wi-Fi), sH/sV s'affichent avec ~ (estimation à partir du HDOP et du type de solution : FIX ≈ 1.2 cm × HDOP). Au contrôle QC cela compte comme «avertissement», pas comme rejet ; la dispersion réelle des époques de la mesure est contrôlée normalement.

Point inaccessible dans le lever

La carte Survey comporte un bouton ✕ Inacc., à côté d'Offset. Inutile de quitter le lever :

  1. Appuyez sur ✕ Inacc. Le schéma à 4 points s'ouvre.
  2. Appuyez sur «● Mesurer le point 1» (ou dites «Prendre»). Puis 2, 3, 4. Le bouton passe seul au suivant.
  3. Vous voyez le résultat, l'angle des droites et un avertissement si la géométrie est faible.
  4. Appuyez sur 💾 Enregistrer dans le lever. Le point prend le numéro suivant du lever et le code en cours. Il s'ajoute à la ligne (si vous mesurez en «Ligne avec code») et la numérotation continue normalement.

L'option «Garder aussi les points auxiliaires dans la liste» détermine si les 4 points auxiliaires restent dans la liste ou sont supprimés. Le choix du haut propose aussi les autres méthodes : distance + azimut au laser, intersection de distances, prolongement de droite.

Point au télémètre laser (DISTO etc.) depuis 2–3 positions

Pour les points que la canne n'atteint pas : angle de bâtiment, poteau, arbre, regard derrière une clôture. Bouton ⟟ Laser dans la carte Survey.

  1. Connectez le laser en «mode clavier» Bluetooth (sur le DISTO : Bluetooth → Keyboard mode) et appairez-le dans Android.
  2. Placez-vous en position 1 et appuyez sur «● Position 1 : mesure GNSS» (ou dites «Prendre»).
  3. Appuyez le laser sur la canne, visez le point et appuyez sur mesurer sur le laser. La distance s'inscrit seule dans le champ. Sans connexion, saisissez-la.
  4. Allez en position 2, à quelques mètres, de sorte que les deux positions forment avec le point un angle de 60°–120°. Refaites la mesure GNSS et la distance.
  5. Il existe deux solutions possibles. Choisissez Gauche / Droite (en regardant de la position 1 vers la 2), ou ajoutez une 3e position : l'application choisit seule et affiche un résidu (RMS) de contrôle.
  6. 💾 Enregistrer dans le lever : le point prend le numéro suivant et votre code.

Dans «Correction de distance», indiquez p. ex. le rayon de la canne, si vous mesurez depuis l'arrière du laser appuyé contre la canne. Pour l'altitude, choisissez «Z moyen des positions + dH». L'application avertit quand la géométrie est faible ou que les distances ne «ferment» pas. La même fonction existe dans COGO → Point par laser et dans Point inaccessible.

Inclinaison ↔ centrage strict

Avec l'IMU active, la carte Survey comporte le bouton ∠ Inclinaison 60°. Un appui le transforme en ⊙ Centrage. Même effet en touchant l'indicateur ∠ de la barre d'état, ou avec les commandes vocales «Centrage» / «Inclinaison».

  • ∠ Inclinaison : vous mesurez avec une canne inclinée, jusqu'à la limite du récepteur.
  • ⊙ Centrage : point uniquement avec canne verticale, dans la tolérance de centrage (p. ex. ±0.5°). Utile pour les points géodésiques, les points de contrôle et les bases. Si vous en sortez, le bouton affiche «⏳ Hors verticale» et attend.
  • Chaque point garde le mode de mesure et l'inclinaison utilisée.

IMU — mesure avec canne inclinée

Si votre récepteur a une IMU, vous mesurez sans caler la nivelle. La compensation se fait dans le récepteur et l'application veille à ce que vous ne mesuriez pas hors des limites du constructeur.

  • Détection automatique : l'application comprend d'elle-même, d'après les données envoyées par le récepteur :
    • Si le récepteur envoie un état de compensation d'inclinaison, l'IMU s'active immédiatement et vous indique, aussi à voix haute, jusqu'à combien de degrés c'est permis.
    • S'il n'envoie qu'un angle d'inclinaison (qui peut aussi venir d'une simple bulle électronique), il vous demande une seule fois si le récepteur a une IMU, et vous saisissez l'inclinaison maximale indiquée dans sa fiche technique. Si vous répondez «Non», seule la bulle de centrage reste.
    • Si le modèle est connu de l'application (p. ex. Emlid Reach RS3 : 60°, CHC i73 : 45°), la limite du constructeur est appliquée. Sinon c'est 30°, tant que vous n'avez pas saisi la limite de la fiche technique.
    • Tout se modifie depuis Menu → IMU / bulle de centrage.
  • Indicateur : la barre d'état affiche ∠ 12°/60°, en vert dans la limite et en rouge au-delà. S'il affiche ∠ INIT, l'IMU doit être initialisée : balancez la canne ou marchez, selon les indications du constructeur.
  • Protection : au-delà de la limite, ou avant la fin de l'initialisation, la mesure ne prend pas de point. Le bouton affiche «⏳ Inclinaison 65° > 60°» et un avertissement sonore retentit. Dès que vous revenez dans la limite, la mesure se fait d'elle-même. Il en va de même en implantation, pour le point inaccessible et en lever continu.
  • Bulle de centrage numérique : petite, à côté des coordonnées, pour ne pas masquer la zone de lever (avec la colonne ouverte en permanence, elle se trouve sur le bouton «Bulle / IMU» de la colonne). Le point indique de quel côté penche la canne et les degrés s'affichent à côté. Vert fluo = vertical, orange = proche, rouge = hors limite. D'un appui, elle s'affiche en grand sur la carte pour un centrage précis (glissez-la où vous voulez), et un nouvel appui la masque. Appui long : réglages bulle / IMU. Avec IMU, le cercle rouge en pointillé représente la limite d'inclinaison du récepteur.
  • Sans IMU (récepteur avec bulle électronique) : la bulle indique la tolérance de verticalité, p. ex. «0.4° · ±0.5°». Vert = centré, orange = proche, rouge = hors limite. Avec l'option «refuser un point hors tolérance de centrage», la mesure attend que vous soyez centré.
  • La bulle est toujours visible. Quand le récepteur envoie l'inclinaison, la bulle vient du récepteur et aucun calibrage n'est nécessaire. Sinon elle vient du capteur du téléphone, avec l'indication «tél.», si le téléphone ou la tablette est sur le support de canne.
  • Calibrage du téléphone — automatique, seulement si nécessaire : si le récepteur n'envoie pas l'inclinaison et que le téléphone n'est pas calibré, ce message s'affiche de lui-même : gardez la pointe de la canne immobile et balancez-la avant-arrière et droite-gauche, de quelques degrés, pendant environ 10″. La barre se remplit et la bulle se calibre seule, sans nivelle et sans boutons. À refaire uniquement si vous changez la position du téléphone sur le support : appui sur la bulle quand elle affiche «Calibr.», ou depuis les réglages de la bulle.
  • Votre propre limite : vous pouvez fixer une limite inférieure à celle du constructeur, p. ex. 30° pour plus de précision.
  • Hauteur : quand le récepteur fournit la position à la pointe de la canne, la hauteur de canne est réglée dans le récepteur et l'application ne la retranche pas à nouveau. Cette option est active par défaut.
  • Enregistrement : chaque point conserve l'inclinaison maximale de la mesure et le modèle du récepteur.
  • L'application contrôle l'angle quand le récepteur l'envoie (messages PASHR, PSAT HPR, PTNL AVR, HPD ou état d'inclinaison Unicore). Si le récepteur n'envoie pas d'angle, elle affiche «∠ IMU» et c'est à vous de respecter la limite du constructeur.
  • Avant le travail, mesurez un point connu avec la canne inclinée. Vous vérifiez ainsi la hauteur de canne et l'initialisation.

Bouton de mesure flottant

Sur la carte se trouve un bouton rond ● MESURER. En implantation il devient violet et affiche ENREGISTRER.

  • Appui = mesure, exactement comme le grand bouton. Pendant la mesure il devient orange (■) et dès que le point est enregistré, vert (✓).
  • Glissement = vous le placez là où votre main est à l'aise et sa position est mémorisée. Pendant le glissement, aucune mesure n'est prise.
  • Réglages → Bouton de mesure flottant : «✋ Gaucher» / «Droitier ✋» l'envoie du côté correspondant. Une option «Gros bouton» existe pour les gants, et vous pouvez aussi le désactiver.
  • Si la carte Survey ou Stakeout s'ouvre en dessous, le bouton remonte automatiquement au-dessus d'elle.

Appels et fonctionnement en arrière-plan

Tant qu'un récepteur est connecté ou qu'un NTRIP ou un static est en cours, l'application fonctionne en priorité, y compris en arrière-plan. Si le téléphone sonne, si vous ouvrez une autre application ou si l'écran s'éteint, rien ne s'arrête :

  • La connexion au récepteur, les corrections NTRIP, le lever continu et l'enregistrement static continuent normalement.
  • Les notifications affichent «HEXIS PAD — Récepteur connecté · NTRIP». Un appui dessus vous ramène dans l'application. La première fois, Android demande l'autorisation des notifications : appuyez sur Autoriser.
  • Pendant un appel, l'application ne parle pas (confirmation vocale), et le micro des commandes vocales se coupe jusqu'à votre retour.
  • Si le Bluetooth est perdu pendant l'appel, la reconnexion se fait d'elle-même, y compris en arrière-plan.
  • La notification disparaît quand vous déconnectez le récepteur et arrêtez le NTRIP.

Sur certains téléphones (Xiaomi, Huawei, Samsung avec «économie de batterie»), réglez HEXIS PAD sur «Sans restrictions» dans les paramètres de batterie d'Android.

7. Implantation (Stakeout)

Point

Cible depuis la liste, avec ◀ ▶ (suivant/précédent), ou ⌖ sur la carte (points, sommets DXF/DWG). Le cercle-cible affiche une flèche quand vous êtes loin et des anneaux gradués de près. Vert = dans la tolérance, avec son et vibration.

Référence de direction : «Référence : déplacement» (Avant/Arrière, Droite/Gauche selon votre sens de marche), «Référence : Nord» (dX/dY), ou «Référence : point» (orientation vers un point, p. ex. en regardant vers un piquet). Déblai / Remblai = Z projet − terrain.

Ligne

Polyligne du dessin (y compris les arcs), deux points, ou ligne mesurée. PK vide = abscisse curviligne et distance perpendiculaire en direct. Avec PK + Offset = cible ; ▶ avance par «Pas».

Surface (dalles, pentes)

Depuis COGO → Pente de dalle : point de référence + pente principale/transversale %, plan par 3 points, ou horizontal. Affiche en direct le Z projet et le Déblai/Remblai.

Équerrage

Ligne de base A→B : PK depuis A et distance perpendiculaire (+droite). Création des 4 angles d'un rectangle avec diagonales de contrôle.

Relocalize — translation des points sur des points connus

Pour des points mesurés avec un faux FIX ou une mauvaise base et qui sont tous décalés. Calculs → Relocalize (ou outil ⇄).

  1. Points à déplacer : tous, ceux mesurés un jour donné, ou du point A au point B. Les points connus et géodésiques ne changent jamais.
  2. Points connus : «＋ Ajouter un point connu» → choisissez le point mesuré, qui a la position erronée. Indiquez ensuite les coordonnées correctes, depuis un point connu de la liste ou en les saisissant.
  3. 1 point connu : translation dX, dY, dZ uniquement. 2 : translation et rotation. 3 ou plus : également contrôle des résidus (RMS), et facteur d'échelle en option.

  5. ↶ Annuler le dernier relocalize : les points reviennent exactement comme avant. Les 10 dernières corrections sont conservées.

9. Systèmes de coordonnées

GGRS87 — modèle officiel HEPOS (par défaut) : la transformation HTRS07 → GGRS87 du Cadastre hellénique (7 paramètres + grilles de corrections dE/dN de 2 km, interpolation bilinéaire), intégrée à l'application — aucun fichier n'est nécessaire. Vérifiée avec les exemples officiels du Cadastre hellénique, avec un écart inférieur à 1 mm. Utilisez-la avec HEPOS et avec les réseaux fournissant de l'ETRS89. Pour Kastellorizo, son modèle spécifique est appliqué (3 translations, TM87 avec lon0 = 27°).

«GGRS87 — 3 paramètres» (EPSG:2100) est approché : sans la grille, l'écart atteint en moyenne ~0,6 m et dépasse 2 m dans certaines zones. Altitudes : le Cadastre hellénique ne fournit pas encore de géoïde officiel avec le paquet HEPOS — les altitudes orthométriques viennent du modèle du récepteur ; pour une précision centimétrique, faites un Calage local sur 2–3 repères altimétriques connus.

Autres pays : l'application choisit le système et le géoïde d'après votre position — voir Travailler à l'étranger. Vous pouvez aussi saisir votre propre définition proj4 pour tout pays. Altitudes : orthométriques du récepteur ou ellipsoïdales. Pour les réseaux locaux : COGO → Calage local.

Travailler à l'étranger

L'application détermine dans quel pays vous êtes à partir de la position du récepteur et applique le système de coordonnées officiel du pays, le modèle de géoïde national pour les altitudes (lorsqu'il est librement disponible) et la liste des réseaux de stations permanentes du pays (l'équivalent local de HEPOS) dans NTRIP.

  • Grèce : tout reste inchangé — GGRS87 / HEPOS, Cadastre hellénique et KAEK — quelle que soit la langue choisie. La langue ne change jamais le système de coordonnées ni les fonds.
  • Hors de Grèce : les couches Cadastre hellénique et KAEK ne sont pas affichées (ni dans la colonne ni dans les fonds).
  • Changement automatique uniquement dans un projet vide. Si le projet contient déjà des points, l'application demande une seule fois : garder le système actuel, changer, ou commencer un nouveau projet dans le nouveau pays. Elle ne change jamais de système en cours de travail.
  • Géoïde : téléchargé la première fois (nécessite internet) et conservé sur l'appareil pour travailler hors ligne. Les altitudes orthométriques sont calculées par H = h − N à partir de la hauteur ellipsoïdale du récepteur. Là où il n'existe pas de modèle national, les altitudes proviennent du récepteur.
  • Manuellement : Récepteur & RTK → Système de coordonnées. On y voit le pays de travail et le géoïde ; vous pouvez désactiver le choix automatique, appuyer sur «Appliquer pour ma position» ou choisir un autre système / votre propre proj4.

11. Fichiers & e-mail

Import

Depuis un e-mail : touchez la pièce jointe → «Ouvrir avec» → HEXIS PAD. L'assistant d'import s'ouvre directement. Si vous l'avez déjà téléchargée : Importer → «Choisir un fichier». La fenêtre s'ouvre directement dans Téléchargements.

Un seul bouton «Choisir un fichier» — le type est détecté automatiquement :

  • DXF, DWG : dessin de fond, avec translation dX/dY facultative et import des POINT comme points d'implantation.

Avant l'import, vous voyez un aperçu : tableau des colonnes (détection automatique Nom / X / Y / Z / Code — modifiez-les si besoin), en-tête oui/non, inversion X↔Y, lat/lon, petit dessin des points, contrôle qu'ils tombent dans la bonne zone, et gestion des noms en double (renommer / ignorer / remplacer).

Choix rapides : Points uniquement (TXT), DXF (points + lignes) ou Tous ; sinon cochez les formats un par un. TXT, CSV complet (précisions, QC, base, écarts d'implantation, photos), DXF (points/noms/altitudes/codes en layers, lignes), KML, GeoJSON, photos — le tout en ZIP. 💾 Enregistrer (Documents/HEXIS PAD), ↗ Partager ou ✉ E-mail (ouvre l'application de messagerie avec les fichiers joints).
