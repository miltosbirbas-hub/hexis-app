1. 시작하기

  1. Android 휴대폰 또는 태블릿에 HEXIS_PAD.apk를 설치합니다 (브라우저/파일 앱에 «알 수 없는 출처에서 설치»를 허용하세요).
  2. 처음 실행 시 라이선스 코드(형식 PAD-XXXX-XXXX-XXXX)를 묻습니다. 입력하고 활성화를 누르세요 — 인터넷은 이때 한 번만 필요합니다. 라이선스를 참고하세요.
  3. 앱 열기 → 요청이 오면 Bluetooth, 위치, 카메라 권한을 허용합니다.
  4. 수신기와 NTRIP 첫 연결: 단계별 첫 연결을 참고하세요.
  5. 앱은 프로젝트 하나와 함께 열립니다. 새 프로젝트, 이름 변경, 전환은 메뉴 → 프로젝트에서 합니다.
  6. 상단 표시줄에는 해(FIX 녹색, FLOAT 주황, SINGLE/DGPS 빨강), 𝜎H / 𝜎V (m, 1𝜎), 위성 수, PDOP, 보정 지연, QC와 NTRIP 표시가 나옵니다. 표시줄을 누르면 → 상세 GNSS 상태.
화면 테마: ☀ 태양(햇빛 아래 최대 대비)과 NEO 다크(저조도). 메뉴 → 설정.

단계별 첫 연결: 수신기와 NTRIP

이 단계는 한 번만 하면 됩니다. 이후 앱이 수신기와 네트워크를 기억하므로, 앱을 열고 수신기를 켜면 자동으로 연결됩니다.

시작 전에 준비하세요: 충전된 수신기, 모바일 데이터(4G/5G)가 켜진 휴대폰, NTRIP 구독 정보: caster host, port, 사용자, 비밀번호. 이 정보는 구독한 상시관측소 망에서 제공합니다.

A. Bluetooth로 수신기 연결

  1. 수신기를 켜고 Bluetooth 표시등이 켜질 때까지 기다리세요.
  2. Android에서 페어링: 휴대폰 설정 → Bluetooth → 새 기기 페어링 → 수신기 선택. 이름은 보통 수신기 밑면 라벨의 일련번호(S/N)입니다. 코드를 물으면: 1234 또는 0000.
    더 빠른 방법: 처음에 앱이 «수신기 첫 연결» 화면을 보여줍니다. «수신기 페어링 (Bluetooth)» 버튼이 Bluetooth 설정을 바로 엽니다. 수신기에 NFC가 있으면 휴대폰을 갖다 대기만 하면 됩니다.
  3. HEXIS PAD로 돌아오세요. 앱이 수신기를 찾아 자동으로 연결합니다. 연결되지 않으면: 홈 → 수신기 & RTK → 수신기 연결 → Bluetooth → 수신기 선택 → 연결.
  4. 처음에 Android가 «근처 기기» 권한을 묻습니다. 허용을 누르세요.
  5. 확인: 상단 표시줄에 SINGLE 또는 DGPS(빨강) 해와 위성 수가 나오면 수신기가 위치를 보내고 있는 것입니다. RTK는 NTRIP으로 얻습니다 (C 단계).

B. 수신기 Wi-Fi로 연결 (Bluetooth가 위치를 보내지 않을 때)

  1. 홈 → 수신기 & RTK → 수신기 Wi-Fi로 연결.
  2. 제조사를 고른 뒤 목록에서 수신기를 선택하세요.
  3. Android가 «기기 검색» 창을 엽니다. 수신기의 Wi-Fi 네트워크 선택 → 연결. 수신기 Wi-Fi는 앱만 사용하고, NTRIP용 인터넷은 모바일 데이터로 계속됩니다.
  4. 이후 수신기가 켜지면 홈의 수신기 카드에 «수신기 발견 · 눌러서 연결»이 표시됩니다. 누르면 연결됩니다. Android의 «기기 검색» 창은 직접 요청할 때만 열리고 저절로 열리지 않습니다. 휴대폰이 이미 수신기 Wi-Fi에 연결되어 있으면 창 없이 자동으로 연결됩니다.

C. NTRIP: 상시관측소 망의 RTK 보정

  1. 홈 → 수신기 & RTK → NTRIP / RTK.
  2. 상시관측소 망: 구독한 망을 선택하세요 (예: HEPOS (그리스 지적)). 다른 망은 «기타 네트워크 / 내 caster»를 선택하고 Caster host와 Port(보통 2101)를 입력합니다.
  3. 구독한 사용자와 비밀번호를 입력하세요.
  4. 목록을 누르면 망의 mountpoint를 불러옵니다. 망에서 안내한 것을 선택하세요. 보통 MSM 형식의 VRS입니다.
  5. «GGA 전송 (VRS / 네트워크에 필수)»을 체크된 상태로 두세요. «수신기 연결 시 자동 시작»도 체크하면 매번 자동으로 시작됩니다.
  6. 💾 프로필 → 이름을 붙여 정보를 저장하세요. 망이나 계정이 두 개면 한 번 눌러 전환합니다.
  7. 시작을 누르세요. 보정이 들어오면 상단 표시줄의 NTRIP 표시가 녹색이 됩니다. 몇 초 내에 (하늘이 가려진 곳에서는 1–2분까지) 해가 FLOAT(주황)에서 FIX(녹색)로 바뀝니다.

D. 작업 전 점검

  • 안테나 높이: 화면 아래쪽 안테나 높이 칸에 폴 높이를 입력하세요. 수신기에 위상중심 offset이 있으면 수신기 연결에서 한 번 설정합니다. 여기가 틀리면 모든 표고가 틀립니다.
  • 좌표계: 홈 → 수신기 & RTK → 좌표계 → GGRS87 (HEPOS). 이렇게 하면 공식 변환 격자가 평면 위치와 표고 모두에 적용됩니다.
  • 상단 표시줄에 작은 𝜎H / 𝜎V의 FIX, 녹색 QC 표시.
  • 측량이나 측설 전에 기지점 하나(예: 삼각점 또는 좌표와 표고를 아는 점)를 측정해 비교하세요.

E. 문제가 있을 때

증상조치
수신기가 목록에 보이지 않음페어링이 안 되었습니다. 수신기 연결 → ⚙ Bluetooth 설정 → 새 기기 페어링.
연결을 누르면 오류수신기가 다른 기기나 제조사 앱에 연결되어 있습니다. 다른 연결을 닫거나 수신기를 껐다 켠 뒤 다시 연결을 누르세요.
«연결됨»인데 위치가 오지 않음수신기가 NMEA를 보내지 않습니다. 앱이 자동으로 활성화 명령을 보내니 몇 초 기다리세요. 그래도 안 되면 Wi-Fi 연결(B)을 시도하거나 🔎 수신기 데이터 샘플을 눌러 지원팀에 보내세요.
«NTRIP용 인터넷이 없습니다»모바일 데이터를 켜세요. 휴대폰이 설정에서 수신기 Wi-Fi에 연결되어 있다면 연결을 끊고 앱에서 수신기를 연결하세요 (B).
mountpoint 목록이 비어 있거나 NTRIP 오류caster host와 port를 확인하세요. 사용자나 비밀번호 오류라면 정보와 구독 활성 여부를 확인하세요.
NTRIP은 녹색인데 DGPS 또는 FLOAT에 머묾«GGA 전송»이 체크되어 있는지, 올바른 mountpoint(VRS / MSM)를 선택했는지 확인하세요. 건물과 나무에서 떨어진 하늘이 트인 곳으로 이동하세요.

홈 화면, 지도, 도구줄

홈 화면(도구줄의 ⌂ 버튼): 위쪽에 프로젝트와 수신기가 있고, FIX, FLOAT, 해 없음에 따라 녹색, 주황, 빨강 점이 표시됩니다. 아래에는 모두 같은 파란색인 여섯 범주가 있습니다:

  • Survey: 측량 시작, 연속, static, laser 점, 접근 불가 점, 음성 명령.
  • Stakeout: 점, 선, 바닥/경사, 직각 측설, 격자.
  • 계산: 모든 COGO, 거리/방위각, 면적, 직선 교점, 경사, 현지 보정.
  • 파일 & 프로젝트: 가져오기, 점, 붙여넣기, 내보내기/이메일, 프로젝트.
  • 수신기 & RTK: 수신기 연결, NTRIP, base/rover, IMU/기포, laser, 좌표계.
  • 설정: 설정, 도구줄 도구, 사용 설명서.

범주를 누르면 그 범주의 항목만 보입니다. 첫 번째 기본 항목은 큰 컬러 버튼입니다. ‹ 뒤로 또는 휴대폰의 뒤로 버튼으로 범주로 돌아갑니다. 오른쪽 위 지도 버튼은 바로 지도로 이동합니다.

전체 화면 지도: 도구줄은 왼쪽에 접혀 있어 지도가 화면 전체 폭을 씁니다. 화면 왼쪽 가장자리(파란 탭 ›)를 누르거나 밀면 열리고, 도구를 고르거나 지도를 누르면, 또는 몇 초 뒤 저절로 닫힙니다. 도구는 «도구줄 도구»에서 추가·제거합니다. 항상 열어 두려면: 설정 → 화면 → 도구줄 → «항상 열림». 위쪽에 FIX, H/V, 위성 수, Age, QC, NTRIP이, 아래쪽에 현재 위치 좌표가 표시됩니다.

2. 수신기 연결

  1. Android Bluetooth 설정에서 수신기를 페어링하세요.
  2. 메뉴 → 수신기 연결 → Bluetooth, 기기 선택 → 연결.
  3. 또는: Wi-Fi / TCP(수신기 IP와 포트), 휴대폰 GPS(방향 확인용) 또는 시뮬레이터(교육 — 지도 길게 누르기 = «그쪽으로 걸어가세요»).

NMEA 0183을 보내는 모든 수신기를 지원합니다. GGA는 필수이며, GST는 𝜎H/𝜎V 정확도를, GSA는 PDOP을 제공합니다. 수신기가 이를 보내지 않으면 «초기화 명령» 칸에 명령을 입력하거나 Base / Rover → Rover 명령을 사용하세요.

자동 연결 — 설정 불필요

  • 처음: 수신기가 없으면 «수신기 첫 연결» 화면이 나옵니다. 수신기를 켜고 «수신기 페어링»을 누른 뒤 Bluetooth 목록에서 선택하세요. 수신기에 NFC가 있으면 휴대폰을 갖다 대세요. 돌아오면 앱이 수신기를 찾아 자동 연결합니다.
  • 그다음부터: 앱을 열고 수신기를 켜세요. 순서는 상관없습니다. 앱이 자동으로 연결하며, 수신기가 아직 꺼져 있으면 몇 초마다 다시 시도합니다. 설정해 두었다면 NTRIP도 자동으로 시작됩니다.
  • NMEA를 보내지 않는 수신기: 앱이 자동으로 활성화 명령을 보냅니다. 또한 대부분 수신기의 공개 프로토콜(Unicore, NovAtel, u-blox, BESTPOS/BESTNAV, NAV-PVT 메시지)에서 위치를 직접 읽습니다. 이 경우 «수신기 프로토콜 인식됨» 메시지가 나옵니다.
  • Wi-Fi 수신기 (Singular XYZ, CHC, South, Stonex, Hi-Target, Emlid): 가장 안정적인 방법은 수신기 Wi-Fi입니다. 수신기 → «📶 수신기 Wi-Fi로 연결» → 제조사 → 목록의 수신기. 앱은 수신기 Wi-Fi를 자기만 사용하고(모바일 데이터는 NTRIP용으로 유지), 위치가 나오는 포트를 스스로 찾아 이후 자동 연결합니다. 수신기가 꺼져 있으면 앱이 백그라운드에서 조용히 Wi-Fi가 나타나는지 확인하고, 켜지는 즉시 창 없이 연결합니다. 출고 시 NMEA를 출력하지 않는 수신기(예: Singular X1 Lite)는 한 번 수신기 페이지가 열려 TCP NMEA-0183 출력(포트 9000, GGA+GST+GSA, 1 Hz)을 활성화하게 합니다 — Bluetooth나 제조사 소프트웨어에는 영향이 없습니다. 수신기가 근처에서 켜져 있으면 «수신기» 카드에 «수신기 발견 · 눌러서 연결»이 표시됩니다. Android의 «기기 검색» 창은 직접 누를 때만 열립니다.
  • 수신기가 제조사의 암호화 프로토콜만 보낸다면, 수신기 Wi-Fi 페이지나 제조사 앱에서 NMEA 출력을 한 번 켜면 됩니다. «🔎 수신기 데이터 샘플»로 앱이 받는 내용을 보내 주시면 지원을 추가할 수 있습니다.
  • 🧪 다른 앱의 Bluetooth 기록: 수신기가 제조사 소프트웨어에만 위치를 보낸다면, 수신기 연결 창에서 «🧪 Bluetooth 기록»을 누르고 4단계(개발자 옵션 → «Bluetooth HCI 스누프 로그», 시작, 제조사 소프트웨어로 연결, 중지 & 전송)를 따른 뒤 파일을 보내 주세요. 카운터가 0 kB에 머물면 «🔍 시스템 파일 찾기 & 전송»을 누르세요: 앱이 Android 기록 파일(btsnoop_hci.log)을 찾아 보냅니다. 수신기 지원은 한 번 추가되면 모든 사용자에게 적용되며, 수신기나 다른 소프트웨어는 변경되지 않습니다.
  • «연결 해제»는 다시 «연결»을 누를 때까지 자동 재연결을 멈춥니다.

수신기가 목록에 안 보이나요? 수신기 연결 창에서 ⚙ Bluetooth 설정 → 새 기기 페어링을 누르고 수신기를 선택하세요. 이름은 보통 수신기 밑면 라벨의 일련번호(S/N)입니다 (예: «2124A0176»). 돌아오면 목록이 자동으로 갱신됩니다. «↻ 목록 새로 고침» 버튼도 있습니다. GNSS 수신기로 추정되는 기기는 ★와 함께 맨 위에, 스피커·자동차·이어폰은 맨 아래에 표시됩니다.

3. NTRIP (상시관측소 망)

모든 NTRIP 망에 연결됩니다: HEPOS, URANUS, CivilPOS, HxGN SmartNet, JGC NET 또는 자체 caster. 연결 정보는 구독한 망에서 제공합니다.

  1. 메뉴 → NTRIP / RTK: caster host, port (보통 2101), 사용자, 비밀번호.
  2. 목록 → caster의 mountpoint를 불러옵니다. 알맞은 것을 선택하세요 (예: VRS / MSM).
  3. «GGA 전송»(VRS에 필수)을 켠 상태로 → 시작.
  4. 데이터가 들어오면 NTRIP 표시가 녹색이 됩니다. 보정은 Bluetooth로 수신기에 전달됩니다. 네트워크가 끊기면 자동으로 재연결합니다.
💾 프로필: 망/계정별로 저장해 빠르게 전환하세요. «자동 시작» = 수신기 연결 시 자동으로 시작.

Leica, Trimble, Topcon, Sokkia, Spectra, GeoMax, CHC기지국/무선 설정은 폐쇄형 — 자체 소프트웨어에서 합니다. HEXIS PAD는 NMEA로 rover로 작동합니다.

모든 명령은 전송 전에 표시됩니다 — 수신기 설명서와 대조하세요 (특히 기지국 높이가 타원체고인지 정표고인지).

새 기지국

  1. ＋ 새 기지국 → 기지점에서(점 선택) 또는 단독 위치 «여기».
  2. 기지국 안테나 높이, RTCM 포트, 지오이드고 N.
  3. 기지국으로 명령… → 확인 → 전송 (기지국과 Bluetooth 연결 상태에서).
  4. 활성 기지국으로 설정: 모든 새 점이 이 기지국에 «연결»됩니다.

기지국 이동

기지국을 단독 측위/잘못된 위치에 설치했다면: 목록에서 기지국 열기 → «사용된 위치»와 «올바른 위치» 입력 → 이동 적용. 기지국의 모든 점이 ∆X/∆Y/∆Z만큼 이동하고 메모에 기록됩니다.

5. Survey (측량)

  1. 점 이름(자동 증가), 코드(최근 코드는 버튼으로), 안테나 높이(폴 + 위상중심).
  2. 시간: 초(1, 2, 3, 5, 10, 15, 30 s, 1분 또는 3분) 또는 에포크. 임의 값은 «기타…». 에포크 = 수신기의 위치 해 1개 (1 Hz에서 1 에포크 ≈ 1 s). 전부 평균합니다. FIX만: FLOAT 에포크는 버립니다.
  3. FIX 대기(설정, 기본 10 s): 해가 이 시간 동안 연속으로 FIX를 유지해야 측정이 시작됩니다. 버튼에 «⏳ FIX 4/10 s»가 표시됩니다.
  4. 점이 저장되면 버튼이 잠시 녹색 «✓ 이름»(소리와 함께)이 되었다가 다음 측정을 위해 돌아옵니다.
  5. 소리(설정 → 소리, 음량과 테스트 포함): 점 저장음, 해가 FIX가 되면 상승음, FIX가 끊기면 낮은 음과 진동.
  6. ● 측정 → 품질 관리가 실행됩니다 (6장). 측정 중 다시 누르면 = 취소.
  7. 코드 선: 같은 코드의 연속된 점이 선으로 연결됩니다 (DXF로 내보냄).
  8. ⌖ Offset: 거리 + 방위각으로 점 (수동 또는 laser).
  9. 이미 있는 이름으로 측정 → 독립 측정 비교 및 «점검으로 저장» 선택.

연속 측량

홈 → ⟳ 연속 측량 (또는 도구줄의 ⟳ 도구). 거리 간격(예: 1 m마다) 또는 시간 간격(예: 2 s마다), 코드, «FIX에서만», 최대 𝜎H를 선택합니다. 걸어가는 동안 점이 자동 저장되고 이름도 자동 증가합니다. 지도 위에 «⟳ 연속 · N 점» 표시줄과 ■ 중지 버튼이 나타납니다. 해가 FIX가 아니거나 𝜎H가 한계를 넘으면 표시줄에 노란 글씨로 이유가 나오고 점은 저장되지 않습니다.

Static

홈 → ◷ Static. 점, 코드, 안테나 높이, 시간(5분~2시간, 또는 «중지할 때까지»)을 입력합니다. 수신기를 고정한 동안 앱은:

  • 초당 해 1개를 받아 평균, 𝜎H, 𝜎V를 계산합니다. FIX 해가 있으면 그것만 사용합니다. FIX가 전혀 없으면 점에 «FIX 없음» 표시가 붙습니다.
  • 후처리를 위해 수신기의 모든 데이터를 Documents/HEXIS PAD/Static/<프로젝트>_<점>_<날짜>.gnss 파일에 기록합니다. 사무실 후처리를 하려면 수신기가 원시 관측값(RTCM3 MSM 또는 제조사 형식)을 출력해야 합니다.
  • 끝나면 결과와 «파일 공유 / 이메일» 버튼을 보여줍니다.

진행 중에 ◷를 다시 누르면 통계를 실시간으로 보고 일찍 끝낼 수 있습니다.

점 대 점 선 그리기

Survey에서 ✎ 도면을 누르고 Draw lines 그룹에서 Line(독립 직선 구간), Polyline(연속선), Spline(점을 지나는 부드러운 곡선) 또는 Polygon(닫힌 다각형)을 선택하세요. 각 버튼에는 모양을 나타내는 아이콘이 있습니다. 이후 측정하는 모든 점이 선에 추가되며, 지도 위에 유형과 점 개수를 보여주는 녹색 표시줄이 나타납니다. 마지막 측정점에서 시작할 수도 있습니다. 표시줄에서: ↶는 선에서 마지막 점을 뺍니다 (점은 남음), ✕는 선을 취소합니다 (모든 점은 남음), ✓ 완료는 선을 마칩니다. DXF 내보내기에서 선은 LINE / POLYLINE / spline은 조밀한 polyline으로, HP_<코드> 레이어에 저장됩니다.

안테나 높이 = 폴 + 수신기 offset

Survey 칸에는 폴 높이만 입력합니다. 안테나 offset(기준점 ARP에서 위상중심까지, 예: Singular X1 Lite / L1은 0.068 m)은 수신기가 인식되면 자동으로 더해지거나, 설정 → «수신기 안테나 Offset»에서 지정합니다. 칸의 라벨에 «폴 (+0.068)»이 표시되고 점 속성에 둘 다 기록됩니다.

GST 없는 위치 오차

수신기가 GST를 보내지 않으면 (예: Wi-Fi 연결 Singular) 𝜎H/𝜎V가 ~와 함께 표시됩니다 (HDOP와 해 유형으로 추정: FIX ≈ 1.2 cm × HDOP). QC에서는 불합격이 아닌 «경고»로 처리되며, 측정 에포크의 실제 분산은 정상적으로 점검됩니다.

측량 중 접근 불가 점

Survey 카드의 Offset 옆에 ✕ 접근불가 버튼이 있습니다. 측량을 벗어날 필요가 없습니다:

  1. ✕ 접근불가를 누르세요. 4개 점이 있는 그림이 열립니다.
  2. «● 점 1 측정»을 누르세요 (또는 «측정»이라고 말하기). 그다음 2, 3, 4. 버튼이 자동으로 다음으로 넘어갑니다.
  3. 결과, 두 직선의 각도, 기하가 약하면 경고가 표시됩니다.
  4. 💾 측량에 저장을 누르세요. 점은 측량의 다음 번호와 현재 코드를 받습니다. («코드 선»을 측정 중이면) 선에 추가되고 번호는 정상적으로 이어집니다.

«보조점도 목록에 유지» 옵션으로 보조점 4개를 목록에 남길지 지울지 정합니다. 위쪽 선택에는 다른 방법도 있습니다: laser 거리 + 방위각, 거리 교점, 직선 연장.

laser 거리측정기(DISTO 등)로 2–3 위치에서 점 측정

폴이 닿지 않는 점용: 건물 모서리, 기둥, 나무, 울타리 너머 맨홀. Survey 카드의 ⟟ Laser 버튼.

  1. laser를 Bluetooth «키보드 모드»로 연결하고 (DISTO: Bluetooth → Keyboard mode) Android에서 페어링하세요.
  2. 위치 1에 서서 «● 위치 1: GNSS 측정»을 누르세요 (또는 «측정»이라고 말하기).
  3. laser를 폴에 대고 점을 조준해 laser에서 측정을 누르세요. 거리가 칸에 자동 입력됩니다. 연결이 없으면 직접 입력합니다.
  4. 몇 미터 떨어진 위치 2로 이동해 두 위치가 점에서 60°–120° 각을 이루게 하세요. 다시 GNSS 측정과 거리를 측정합니다.
  5. 가능한 해가 두 개입니다. 왼쪽 / 오른쪽을 선택하거나 (위치 1에서 2를 바라볼 때), 3번째 위치를 추가하세요: 앱이 자동으로 선택하고 점검용 잔차(RMS)를 보여줍니다.
  6. 💾 측량에 저장: 점은 다음 번호와 코드를 받습니다.

«거리 보정»에는 예컨대 폴에 댄 laser 뒷면으로 측정할 경우 폴의 반지름을 넣습니다. 표고는 «위치 평균 Z + ∆H»를 선택하세요. 기하가 약하거나 거리가 «맞지» 않으면 앱이 경고합니다. 같은 기능이 COGO → laser 점과 접근 불가 점에도 있습니다.

기울기 ↔ 엄격한 연직

IMU가 활성일 때 Survey 카드에 ∠ 기울기 60° 버튼이 있습니다. 누르면 ⊙ 연직으로 바뀝니다. 상태 표시줄의 ∠ 표시를 누르거나 음성 명령 «연직» / «기울기»로도 같은 동작을 합니다.

  • ∠ 기울기: 수신기 한계까지 기울인 폴로 측정합니다.
  • ⊙ 연직: 구심 허용오차(예: ±0.5°) 이내의 연직 폴로만 점을 측정합니다. 삼각점, 점검점, 기지국에 유용합니다. 벗어나면 버튼에 «⏳ 연직 벗어남»이 표시되고 대기합니다.
  • 모든 점은 어떤 방식으로, 얼마나 기울여 측정했는지 기록합니다.

IMU — 기울인 폴로 측정

수신기에 IMU가 있으면 수평을 맞추지 않고 측정합니다. 보정은 수신기 내부에서 이루어지며, 앱은 제조사 한계를 벗어나 측정하지 않도록 관리합니다.

  • 자동 인식: 앱이 수신기가 보내는 데이터로 스스로 판단합니다:
    • 수신기가 기울기 보정 상태를 보내면 IMU가 즉시 활성화되고, 허용 각도를 음성으로도 알려줍니다.
    • 기울기 각도만 보내면 (단순 전자 기포일 수도 있음) 수신기에 IMU가 있는지 한 번 묻고, 사양서의 최대 기울기를 입력하게 합니다. «아니요»라고 답하면 구심 기포만 남습니다.
    • 앱이 아는 모델이면 (예: Emlid Reach RS3: 60°, CHC i73: 45°) 제조사 한계가 적용됩니다. 그렇지 않으면 사양서 한계를 입력할 때까지 30°가 적용됩니다.
    • 모든 설정은 메뉴 → IMU / 구심 기포에서 바꿀 수 있습니다.
  • 표시: 상태 표시줄에 ∠ 12°/60°가 표시되며, 한계 이내면 녹색, 벗어나면 빨강입니다. ∠ INIT이 표시되면 IMU 초기화가 필요합니다: 제조사 지침대로 폴을 흔들거나 걸으세요.
  • 보호: 한계를 넘거나 초기화가 끝나기 전에는 측정이 점을 받지 않습니다. 버튼에 «⏳ 기울기 65° > 60°»가 표시되고 경고음이 납니다. 한계 안으로 들어오면 측정이 자동으로 진행됩니다. 측설, 접근 불가 점, 연속 측량에도 똑같이 적용됩니다.
  • 디지털 구심 기포: 측량 영역을 가리지 않도록 좌표 옆에 작게 표시됩니다 (도구줄을 항상 열어 두면 도구줄의 «기포 / IMU» 버튼에 있음). 점은 폴이 기운 방향을 가리키고 옆에 각도가 표시됩니다. 형광 녹색 = 연직, 주황 = 근접, 빨강 = 벗어남. 한 번 누르면 정밀 구심을 위해 지도 위에 크게 표시되고 (원하는 곳으로 드래그), 다시 누르면 숨겨집니다. 길게 누르기: 기포 / IMU 설정. IMU가 있으면 빨간 점선 원이 수신기의 기울기 한계입니다.
  • IMU 없음 (전자 기포 수신기): 기포가 연직 허용오차를 표시합니다 (예: «0.4° · ±0.5°»). 녹색 = 구심 맞음, 주황 = 근접, 빨강 = 벗어남. «구심 허용오차를 벗어나면 점을 받지 않음» 옵션을 켜면 구심이 맞을 때까지 측정이 대기합니다.
  • 기포는 항상 표시됩니다. 수신기가 기울기를 보내면 수신기 값으로 표시하며 보정이 전혀 필요 없습니다. 그렇지 않으면 휴대폰이나 태블릿이 폴 거치대에 있을 때 휴대폰 센서 값으로 «휴대폰» 표시와 함께 나타냅니다.
  • 휴대폰 보정 — 자동, 필요할 때만: 수신기가 기울기를 보내지 않고 휴대폰이 보정되지 않았다면 메시지가 저절로 나옵니다: 폴 끝을 고정한 채 앞뒤와 좌우로 흔드세요, 몇 도씩, 약 10″ 동안. 진행 막대가 차면 기포가 수평기나 버튼 없이 자동 보정됩니다. 거치대에서 휴대폰 위치를 바꿀 때만 다시 합니다: «보정»이 표시될 때 기포를 누르거나 기포 설정에서.
  • 사용자 한계: 더 높은 정확도를 위해 제조사보다 작은 한계(예: 30°)를 설정할 수 있습니다.
  • 높이: 수신기가 폴 끝 위치를 출력하면 폴 높이는 수신기에서 설정하며 앱은 다시 빼지 않습니다. 이 옵션은 기본으로 켜져 있습니다.
  • 기록: 모든 점은 측정 중 최대 기울기와 수신기 모델을 저장합니다.
  • 앱은 수신기가 각도를 보낼 때 점검합니다 (PASHR, PSAT HPR, PTNL AVR, HPD 메시지 또는 Unicore 기울기 상태). 수신기가 각도를 보내지 않으면 «∠ IMU»가 표시되며 제조사 한계는 직접 지켜야 합니다.
  • 작업 전에 기울인 폴로 기지점을 측정하세요. 그러면 폴 높이와 초기화를 확인할 수 있습니다.

플로팅 측정 버튼

지도 위에 둥근 ● 측정 버튼이 있습니다. 측설에서는 보라색으로 바뀌고 기록이 표시됩니다.

  • 누르기 = 측정, 큰 버튼과 똑같습니다. 측정 중에는 주황(■), 점이 저장되면 녹색(✓)이 됩니다.
  • 드래그 = 손에 편한 곳으로 옮기며 위치를 기억합니다. 드래그할 때는 측정하지 않습니다.
  • 설정 → 플로팅 측정 버튼: «✋ 왼손잡이» / «오른손잡이 ✋»로 해당 쪽으로 보냅니다. 장갑용 «큰 버튼» 옵션이 있고, 끌 수도 있습니다.
  • Survey나 Stakeout 카드가 아래에서 열리면 버튼이 자동으로 그 위로 올라갑니다.

통화와 백그라운드 작동

수신기가 연결되어 있거나 NTRIP 또는 static이 실행 중이면 앱은 우선순위를 가지고 백그라운드에서도 작동합니다. 전화가 오거나, 다른 앱을 열거나, 화면이 꺼져도 아무것도 멈추지 않습니다:

  • 수신기 연결, NTRIP 보정, 연속 측량, static 기록이 정상적으로 계속됩니다.
  • 알림에 «HEXIS PAD — 수신기 연결됨 · NTRIP»이 표시됩니다. 누르면 앱으로 돌아갑니다. 처음에 Android가 알림 권한을 묻습니다: 허용을 누르세요.

7. Stakeout (측설)

점

목록에서 목표 선택, ◀ ▶(다음/이전), 또는 지도에서 ⌖ (점, DXF/DWG 꼭짓점). 목표 원은 멀리 있을 때 화살표를, 가까우면 눈금 고리를 보여줍니다. 녹색 = 허용오차 이내, 소리와 진동 포함.

방향 기준: «기준: 이동» (걷는 방향 기준 앞/뒤, 오른쪽/왼쪽), «기준: 북쪽» (∆X/∆Y), 또는 «기준: 점» (점 방향으로 정렬, 예: 말뚝을 바라보며). 절토 / 성토 = 설계 Z − 지반.

선

도면 폴리라인(호 포함), 두 점, 또는 측정된 선. 빈 Sta. = 실시간 측점거리와 수직 거리. Sta. + Offset = 목표; ▶는 «간격»만큼 진행합니다.

면 (바닥, 경사)

COGO → 바닥 경사에서: 기준점 + 주/횡단 경사 %, 3점 평면, 또는 수평. 설계 Z와 절토/성토를 실시간으로 표시합니다.

직각 측설

기준선 A→B: A로부터의 Sta.와 수직 거리(+오른쪽). 점검용 대각선과 함께 직사각형 모서리 4개를 생성합니다.

⛶ 큰 숫자의 전체 화면 측설. ● 기록: 측설점을 측정해 목표 이름 + «n»(예: P1 → P1n)으로, 목표 대비 ∆X/∆Y/∆Z와 함께 측설 화면을 벗어나지 않고 저장합니다. 그다음 자동으로 다음 점으로 이동합니다. 📄 측설 확인 파일: 목표, 측설점, 편차, 허용오차 이내/초과 표시가 있는 CSV와 TXT — 저장, 공유 또는 이메일. 허용오차: 설정.

Relocalize — 점을 기지점에 맞춰 이동

잘못된 FIX나 잘못된 기지국으로 측정해 모두 어긋난 점들을 위한 기능입니다. 계산 → Relocalize (또는 ⇄ 도구).

  1. 이동할 점: 전체, 특정 날짜에 측정한 점, 또는 점 A부터 B까지. 기지점과 삼각점은 절대 변경되지 않습니다.
  2. 기지점: «＋ 기지점 추가» → 잘못된 위치를 가진 측정된 점을 선택합니다. 그다음 목록의 기지점에서 가져오거나 직접 입력해 올바른 좌표를 지정합니다.
  3. 기지점 1개: ∆X, ∆Y, ∆Z 이동만. 2개: 이동과 회전. 3개 이상: 잔차(RMS) 점검과 선택적 축척까지.
  4. ∆X, ∆Y, ∆Z, 회전, 잔차를 확인하고 적용을 누르세요. 모든 점이 올바른 위치로 이동하고 각 점의 메모에 보정 내용이 기록됩니다.
  5. ↶ 마지막 relocalize 취소: 점이 정확히 원래대로 돌아갑니다. 최근 10개의 보정이 보관됩니다.

9. 좌표계

GGRS87 — HEPOS 공식 모델 (기본값): 그리스 지적의 HTRS07 → GGRS87 변환 (7 파라미터 + 2 km dE/dN 보정 격자, 쌍선형 보간)이 앱에 내장되어 있어 별도 파일이 필요 없습니다. 그리스 지적의 공식 예제로 검증했으며 차이는 1 mm 미만입니다. HEPOS 및 ETRS89를 제공하는 망과 함께 사용하세요. 카스텔로리조에는 전용 모델(이동 3개, TM87, 𝜆0 = 27°)이 적용됩니다.

«GGRS87 — 3 파라미터» (EPSG:2100)는 근사값입니다: 격자 없이 평균 ~0,6 m, 일부 지역에서는 2 m 이상 차이가 납니다. 표고: 그리스 지적은 아직 HEPOS 패키지와 함께 공식 지오이드를 제공하지 않으므로 정표고는 수신기 모델에서 가져옵니다. cm급 정확도가 필요하면 표고를 아는 기지점 2–3개로 현지 보정을 하세요.

기타 국가: 앱이 위치에 따라 좌표계와 지오이드를 자동으로 선택합니다 — 해외 작업 참조. 모든 국가에 대해 사용자 정의 proj4를 입력할 수도 있습니다. 표고: 수신기 정표고 또는 타원체고. 지역 망: COGO → 현지 보정.

해외 작업

앱은 수신기 위치로부터 현재 있는 국가를 스스로 파악하여, 해당 국가의 공식 좌표계, 표고용 국가 지오이드 모델(무료로 제공되는 경우), 그리고 해당 국가의 상시관측소 망 목록(현지의 HEPOS에 해당)을 NTRIP에 설정합니다.

  • 그리스: 모든 것이 그대로 유지됩니다 — GGRS87 / HEPOS, 그리스 지적, KAEK — 어떤 언어를 선택했든 마찬가지입니다. 언어는 좌표계나 배경지도를 절대 바꾸지 않습니다.
  • 그리스 외 지역: 그리스 지적과 KAEK 레이어는 표시되지 않습니다(도구줄과 배경지도 모두).
  • 자동 변경은 빈 프로젝트에서만. 프로젝트에 이미 점이 있으면 앱이 한 번만 묻습니다: 현재 좌표계 유지, 변경, 또는 새 국가에서 새 프로젝트 시작. 작업 도중에 좌표계를 바꾸는 일은 없습니다.
  • 지오이드: 처음에 다운로드되며(인터넷 필요) 오프라인 작업을 위해 기기에 저장됩니다. 정표고는 수신기의 타원체고로부터 H = h − N으로 계산됩니다. 국가 모델이 없는 곳에서는 표고를 수신기에서 받습니다.
  • 수동: 수신기 & RTK → 좌표계. 작업 국가와 지오이드가 표시되며, 자동 선택을 끄거나 «내 위치에 적용»을 누르거나 다른 좌표계 / 사용자 정의 proj4를 선택할 수 있습니다.

10. 지도 & 배경지도

도구줄에서: ▦ 지적은 흰 지도 위의 필지 경계와 KAEK를 켜고 끄며, ◐ 위성은 흰 지도/위성 지도를 전환합니다. ≣ → 배경지도: Esri 위성 / 도로 / 지형도, OpenStreetMap, Google (설정에 자신의 Map Tiles API key 입력 시). 오버레이: Esri 지명, 그리스 지적 (필지 경계 WMS), HEXIS KAEK (KAEK 경계와 번호). DXF/DWG 레이어 표시 여부도 설정합니다.

지도에서 점 누르기 = Stakeout, ✎ 속성 (이름, 코드, X/Y/Z, 유형, 메모), ℹ 상세, 🗑 삭제. 도면 꼭짓점/선 누르기 = Stakeout 또는 새 점. 두 번 누르기 = 확대. 📏 = 지도에서 길이/면적 측정. ◎ = 위치 따라가기. ⤢ = 전체 보기.

11. 파일 & 이메일

가져오기

이메일에서: 첨부파일을 누르세요 → «연결 프로그램» → HEXIS PAD. 가져오기 마법사가 바로 열립니다. 이미 다운로드했다면: 가져오기 → «파일 선택». 창이 바로 다운로드 폴더에서 열립니다.

«파일 선택» 버튼 하나 — 형식은 자동 인식됩니다:

  • TXT, CSV, XYZ, PNT, DAT: 구분자 무관 (쉼표, 세미콜론, tab, 공백), 소수점 쉼표 또는 마침표, 그리스어 인코딩.
  • XLS, XLSX, ODS: 시트 선택.
  • DXF, DWG: 배경 도면, 선택적 ∆X/∆Y 이동과 POINT를 측설점으로 가져오기.
  • KML, GeoJSON: 위도, 경도 점 → 프로젝트 좌표계로 변환.
  • 붙여넣기: 이메일, Excel, 메시지의 텍스트.

가져오기 전에 미리보기가 나옵니다: 열 표 (이름 / X / Y / Z / 코드 자동 인식 — 필요하면 변경), 머리글 예/아니요, X↔Y 전환, 위도/경도, 점의 작은 도면, 올바른 지역에 있는지 점검, 중복 이름 처리 (이름 변경 / 건너뛰기 / 덮어쓰기).

다른 앱에서 (Gmail, 파일, Drive, Viber): 연결 프로그램 또는 공유 → HEXIS PAD. 브라우저를 쓰는 태블릿: 파일을 지도 위로 끌어다 놓으세요.

내보내기

빠른 선택: 점만 (TXT), DXF (점 + 선) 또는 전체. 아니면 형식을 하나씩 체크합니다. 점은 내부적으로 전체 정밀도로 저장되며, 내보낼 때 좌표는 소수 4자리(0.1 mm)로 기록됩니다 — 설정 → «내보내기 좌표 소수 자릿수»에서 3 또는 5로 변경할 수 있습니다.

TXT, 전체 CSV (정밀도, QC, 기지국, 측설 편차, 사진), DXF (레이어별 점/이름/표고/코드, 선), KML, GeoJSON, 사진 — 모두 ZIP으로. 💾 저장 (문서/HEXIS PAD), ↗ 공유 또는 ✉ 이메일 (파일이 첨부된 메일 앱을 엽니다).

모든 내보내기에 사진 포함: 어떤 빠른 선택(«점만», «DXF», «전체»)을 하든 점의 사진이 항상 함께 포함됩니다. photos/ 폴더가 있는 ZIP 파일 하나에 담기며, 각 사진 이름은 점 이름입니다. 측설 파일(CSV + TXT + 사진)도 마찬가지입니다. 한 번의 전송에서 사진이 필요 없으면 «점 사진»의 체크를 해제하세요.

배터리와 전원

  • 화면 켜짐 유지 «작업 중에만» (기본값): 수신기가 연결되어 있고 최근 10분 내에 화면을 터치했거나, 측설·연속 측량·static이 실행 중이면 화면이 켜져 있습니다. 그 외에는 평소처럼 꺼지며, 수신기 연결과 NTRIP은 백그라운드에서 계속됩니다. 한 번 터치하면 다시 켜지고 하던 곳으로 돌아갑니다.
  • 지도는 보이는 것이 바뀔 때만 다시 그립니다: 이동하거나 해가 바뀔 때. 가만히 서 있으면 처리량이 약 1/4로 줄어듭니다.
  • 절전: 충전 중이 아닐 때 배터리 30% 미만이면 자동으로 켜집니다. 이때 지도와 표시가 초당 2회 갱신되고, 화면은 터치 없이 10분 대신 3분 뒤 꺼집니다.
  • 기포는 절대 영향을 받지 않습니다: 항상 실시간으로 작동합니다.
  • 모든 항목은 설정 → 전원에서 설정합니다: «화면 켜짐 유지» (작업 중에만 / 항상 / 휴대폰 설정대로)와 «절전» (자동 / 항상 / 안 함).
  • 팁: 화면 밝기가 가장 큰 소모 요인입니다. 햇빛 아래에서는 밝게 해야 하지만, 그늘이나 저녁에는 휴대폰에서 낮추세요.

라이선스

  • 코드는 처음 입력한 기기에 잠깁니다. 다른 기기에서는 작동하지 않습니다. 휴대폰을 바꾸면 해제를 요청하세요.
  • 사용 시간 라이선스 (예: 현장 7시간 또는 10시간): 앱이 화면에 열려 있는 시간만 계산됩니다 — 화면이 꺼지거나 앱을 나가면 계산이 멈춥니다. 소진 30′ 전과 10′ 전에 경고합니다. 시간은 «라이선스»에 표시된 날짜까지 유효합니다.
  • 기간제 체험 라이선스: 일수는 활성화 시점부터 계산됩니다.
  • 두 종류 모두 현장에서 인터넷 없이 정상 작동하며, 사용 시간은 연결될 때 전송됩니다. 라이선스는 인터넷이 있을 때마다 자동으로 확인되며, 기기가 7일 이상 (소유자 기기는 30일) 인터넷에 전혀 연결되지 않으면 짧은 확인을 요청합니다: 모바일 데이터를 켜고 활성화를 누르세요.
  • 라이선스는 서버 서명이 되어 있고 앱은 정품 버전인지 확인합니다. HEXIS PAD는 hexis-app.gr/pad.html에서만 다운로드하세요. 변조된 버전은 열리지 않습니다.
  • 설정 → 라이선스: 코드, 남은 시간 또는 일수, 사용량, 정확한 만료일을 확인합니다. 지금 확인으로 즉시 갱신됩니다 (예: 연장 후).
  • 만료되거나 시간이 소진되면 코드 화면이 열립니다. 프로젝트와 점은 기기에 남아 있습니다. 연장 후 같은 코드로 다시 활성화를 누르면 하던 곳부터 계속합니다.
  • 기기 시간이 정확해야 합니다. 시간이 뒤로 돌아가면 앱이 인터넷 확인을 요청합니다.
  • 본인 기기 (소유자): 코드 화면에서 «HEXIS-APP 계정으로 소유자 로그인»을 누르고 hexis-app.gr 이메일과 비밀번호를 입력하세요. 관리자 계정은 원하는 모든 기기(휴대폰, 태블릿)를 만료와 시간 계산 없이 영구적으로 잠금 해제합니다. 비밀번호는 기기에 저장되지 않습니다.
  • 코드, 연장 또는 구매: 693 322 6314 (전화 · WhatsApp · Viber).

12. 사진

Survey(마지막 점), 측설(마지막 측설점) 또는 점 상세에서 📷. 모든 사진에는 이름, 코드, 좌표, 날짜, 해 정보가 워터마크로 들어가며 점 이름으로 내보내집니다.

저장 위치: 모든 사진은 해당 점에 연결되어 프로젝트에 보관됩니다. 점 상세에서 열고 내보내기 → 사진 (ZIP) / 이메일로 내보냅니다. 또한 앱을 삭제해도 잃어버리지 않도록 휴대폰에 복사본이 문서/HEXIS PAD/사진/<프로젝트>/ 폴더에 점 이름으로 자동 저장됩니다. 복사본은 설정 → «모든 사진을 휴대폰에 복사»에서 끌 수 있습니다.

측설 중 기록: 점에 도착하면 ● 기록을 누르세요. 목표 대비 ∆X / ∆Y / ∆Z 편차와 함께 새 점(예: «3n»)으로 측정되어 측설 파일에 들어갑니다.
