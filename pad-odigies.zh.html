1. 入门

  1. 在 Android 手机或平板上安装 HEXIS_PAD.apk(为浏览器/文件管理器允许「安装未知来源应用」)。
  2. 首次使用时需要输入许可证代码(格式 PAD-XXXX-XXXX-XXXX)。输入后点 激活 — 仅这一次需要联网。参见许可证。
  3. 打开应用 → 在提示时授予 Bluetooth、位置和相机权限。
  4. 首次连接接收机和 NTRIP:参见首次连接分步说明。
  5. 应用打开时带有一个项目。菜单 → 项目 可新建项目、重命名、切换。
  6. 顶部状态栏显示:解状态(FIX 绿色,FLOAT 橙色,SINGLE/DGPS 红色)、sH / sV(m,1 sigma)、卫星数、PDOP、改正龄期、QC 和 NTRIP 指示。点击状态栏 → 详细 GNSS 状态。
显示主题:☀ 阳光(强光下最大对比度)和 NEO 深色(弱光环境)。菜单 → 设置。

首次连接分步说明:接收机和 NTRIP

这些步骤只需做一次。之后应用会记住接收机和网络:打开应用,打开接收机,它们会自动连接。

开始前请准备好:充好电的接收机、已打开移动数据 (4G/5G) 的手机,以及 NTRIP 订阅信息:caster host、port、用户名和密码。这些由您订阅的 CORS 网络提供。

A. 通过 Bluetooth 连接接收机

  1. 打开接收机,等待 Bluetooth 指示灯亮起。
  2. 在 Android 中配对:手机设置 → Bluetooth → 配对新设备 → 选择接收机。其名称通常是接收机底部铭牌上的序列号 (S/N)。如要求输入代码:1234 或 0000。
    更快的方法:首次使用时应用会显示「首次连接接收机」界面。「配对接收机 (Bluetooth)」按钮会直接打开 Bluetooth 设置。如接收机有 NFC,只需将手机贴近它即可。
  3. 返回 HEXIS PAD。它会自动找到并连接接收机。如未连接:主页 → 接收机和 RTK → 连接接收机 → Bluetooth → 选择接收机 → 连接。
  4. 首次使用时 Android 会请求「附近的设备」权限。点允许。
  5. 检查:顶部状态栏显示 SINGLE 或 DGPS 解(红色)和卫星数。说明接收机正在发送位置。RTK 需要 NTRIP(步骤 C)。

B. 通过接收机 Wi-Fi 连接(当 Bluetooth 不发送位置时)

  1. 主页 → 接收机和 RTK → 通过接收机 Wi-Fi 连接。
  2. 选择厂商,然后从列表中选择接收机。
  3. Android 会打开「搜索设备」窗口。选择接收机的 Wi-Fi 网络 → 连接。接收机的 Wi-Fi 仅供本应用使用,NTRIP 的互联网仍通过移动数据。
  4. 此后每当接收机开机,主页上的接收机卡片会显示「已找到接收机 · 点击连接」。点击即可连接。Android 的「搜索设备」窗口只在您主动请求时才打开,不会自行弹出。如果手机已连接到接收机的 Wi-Fi,则自动连接,不弹窗。

C. NTRIP:来自 CORS 网络的 RTK 改正

  1. 主页 → 接收机和 RTK → NTRIP / RTK。
  2. CORS 网络:选择您订阅的网络(例如 HEPOS(希腊地籍))。其他网络请选择「其他网络 / 自建 caster」并输入 Caster host 和 Port(通常为 2101)。
  3. 输入订阅的用户名和密码。
  4. 点列表:获取网络的 mountpoint。选择网络服务商指定的那个,通常是 MSM 格式的 VRS。
  5. 保持勾选「发送 GGA(VRS / 网络必需)」。同时勾选「接收机连接后自动开始」,以便每次自动启动。
  6. 💾 配置 → 用一个名称保存这些信息。如有两个网络或账户,一键即可切换。
  7. 点开始。收到改正数时,顶部状态栏的 NTRIP 指示变为绿色。几秒钟内(视野不佳时最多 1–2 分钟),解会从 FLOAT(橙色)变为 FIX(绿色)。

D. 作业前检查

  • 天线高:在屏幕下方的天线高字段中输入对中杆高度。如接收机有相位中心偏移,在 连接接收机 中设置一次即可。此处出错意味着所有高程都出错。
  • 坐标系:主页 → 接收机和 RTK → 坐标系 → GGRS87 (HEPOS)。这样平面和高程都会应用官方转换格网。
  • 顶部状态栏显示 FIX,sH / sV 较小,QC 指示为绿色。
  • 在测量或放样之前,先测量一个已知点(例如三角点或已知坐标和高程的点)并进行比较。

E. 出现问题时

现象处理方法
列表中看不到接收机尚未配对。连接接收机 → ⚙ Bluetooth 设置 → 配对新设备。

「NTRIP 无网络」打开移动数据。如果手机已在系统设置中连接到接收机的 Wi-Fi,请断开该 Wi-Fi,并从应用中连接接收机 (B)。

主屏幕、地图和工具栏

主屏幕(工具栏中的 ⌂ 按钮):上方显示项目和接收机,用绿色、橙色或红色圆点表示 FIX、FLOAT 或无解。下方有六个类别,均为同一种蓝色:

  • 测量:开始测量、连续测量、static、激光测点、不可达点、语音指令。
  • 放样:点、线、地面/坡度、直角定位、格网。
  • 计算:全部 COGO、距离/方位角、面积、直线交会、坡度、局部校正。
  • 文件和项目:导入、点、粘贴、导出/邮件、项目。
  • 接收机和 RTK:连接接收机、NTRIP、base/rover、IMU/气泡、激光、坐标系。
  • 设置:设置、工具栏工具、使用手册。

点击一个类别时,只显示该类别的选项。第一个(主要的)是大的彩色按钮。用 ‹ 返回 或手机的返回键回到类别列表。右上角的地图按钮直接进入地图。

地图全屏:工具栏收起在左侧,让地图占满整个宽度。从屏幕左边缘点击或滑动(蓝色标签 ›)即可打开;选择工具后、点击地图后或几秒钟后自动关闭。工具可在「工具栏工具」中添加和移除。如希望一直打开:设置 → 屏幕 → 工具栏 →「始终打开」。上方显示 FIX、H/V、卫星数、Age、QC 和 NTRIP,下方显示当前位置坐标。

2. 连接接收机

  1. 在 Android 的 Bluetooth 设置 中配对接收机。
  2. 菜单 → 连接接收机 → Bluetooth,选择设备 → 连接。
  3. 或者:Wi-Fi / TCP(接收机的 IP 和端口)、手机 GPS(仅用于定向)或模拟器(培训 — 在地图上长按 =「走到那里」)。

支持任何 NMEA 0183 接收机。GGA 为必需;GST 提供 sH/sV 精度,GSA 提供 PDOP。如接收机不发送这些消息,请在「初始化指令」字段中输入指令,或使用 Base / Rover → Rover 指令。

自动连接 — 无需设置

  • 首次:如果没有接收机,会出现「首次连接接收机」界面。打开接收机,点「配对接收机」并在 Bluetooth 列表中选择它。如接收机有 NFC,将手机贴近它。返回后,应用会自动找到并连接它。
  • 以后每次:打开应用并打开接收机,顺序不限。应用会自动连接;如接收机仍未开机,每隔几秒重试一次。之后 NTRIP(如已设置)也会自动启动。
  • 不发送 NMEA 的接收机:应用会自动向其发送启用指令。它还能直接读取大多数接收机公开协议中的位置(Unicore、NovAtel、u-blox,BESTPOS/BESTNAV、NAV-PVT 消息)。此时会显示「已识别接收机协议」。
  • 带 Wi-Fi 的接收机(Singular XYZ、CHC、South、Stonex、Hi-Target、Emlid):最稳定的方式是接收机的 Wi-Fi。接收机 →「📶 通过接收机 Wi-Fi 连接」→ 厂商 → 从列表中选择接收机。应用连接接收机 Wi-Fi 仅供自身使用(移动数据留给 NTRIP),自动找到输出位置的端口,此后自动连接。接收机关机时,应用在后台静默检查其 Wi-Fi 是否出现,开机后立即自动连接 — 不弹窗。对于出厂不输出 NMEA 的接收机(例如 Singular X1 Lite),会打开一次接收机页面,以启用 TCP NMEA-0183 输出(端口 9000,GGA+GST+GSA,1 Hz)— 这不会影响 Bluetooth 或厂商软件。接收机在附近开机时,「接收机」卡片显示「已找到接收机 · 点击连接」。Android 的「搜索设备」窗口只在您点击时才打开。
  • 如果接收机只发送厂商加密协议,需从接收机的 Wi-Fi 页面或其应用中开启一次 NMEA 输出。通过「🔎 接收机数据样本」可以发送应用收到的内容,以便添加支持。
  • 🧪 抓取其他应用的 Bluetooth 数据:如果接收机只向厂商软件发送位置,请在 连接接收机 窗口中点「🧪 Bluetooth 抓包」,按 4 个步骤操作(开发者选项 →「Bluetooth HCI 信息收集日志」、开始、用厂商软件连接、停止并发送),然后将文件发给我们。如计数器停在 0 kB,点「🔍 查找并发送系统文件」:应用会自动找到 Android 的日志文件 (btsnoop_hci.log) 并发送。接收机支持只需为所有用户添加一次;不会更改接收机或其他软件的任何设置。
  • 「断开」会停止自动重连,直到再次点「连接」。

列表中看不到接收机?在 连接接收机 窗口中点 ⚙ Bluetooth 设置 → 配对新设备,然后选择接收机。其名称通常是接收机底部铭牌上的序列号 (S/N),例如「2124A0176」。返回后列表会自动刷新。也可使用「↻ 刷新列表」按钮。可能的 GNSS 接收机以 ★ 排在最前,音箱、汽车和耳机排在最后。

3. NTRIP(CORS 网络)

可连接任何 NTRIP 网络:HEPOS、URANUS、CivilPOS、HxGN SmartNet、JGC NET 或自建 caster。连接信息由网络服务商随订阅提供。

  1. 菜单 → NTRIP / RTK:caster host、port(通常为 2101)、用户名、密码。
  2. 列表 → 获取 caster 的 mountpoint。选择合适的(例如 VRS / MSM)。
  3. 保持启用「发送 GGA」(VRS 必需)→ 开始。
  4. 收到数据时 NTRIP 指示变为绿色。改正数通过 Bluetooth 转发给接收机。网络中断时会自动重连。

基准站信息

点击屏幕顶部的状态栏（FIX、H/V、卫星数、Age）。「GNSS 状态」窗口首先显示你当前所用的基准站：网络（例如 HxGN SmartNet）、mountpoint、基站编号、项目坐标系中的基准站坐标、B/L、椭球高和 ECEF、天线高、基准站天线和接收机、距基站距离以及 Age。这些信息直接读取自改正数电文本身（RTCM 1005/1006、1033），因此会在 NTRIP 启动几秒后显示。

在 VRS 网络（虚拟基站）中，坐标为 caster 在你附近生成的虚拟基站坐标。使用单基站时，则为真实基站的坐标。
💾 配置:保存每个网络/账户,便于快速切换。「自动开始」= 接收机连接后自动启动。

4. Base / Rover 和更换基准站

接收机厂商

菜单 → Base / Rover:选择品牌(CHC、South、Stonex、Hi-Target、ComNav、Singular XYZ、Kolida、Ruide、Tersus、SatLab、FOIF、Emlid、ArduSimple、Septentrio、Leica、GeoMax、Trimble、Spectra、Topcon、Sokkia)。系统会推荐主板的指令系列;如您的型号不同,请更改。

指令系列HEXIS PAD 的功能
Unicore, NovAtel/ComNav, Septentrio架设基准站(已知点或「此处」),在电台端口启用 RTCM3 输出,设置 rover 和 NMEA 输出。
u-blox(Emlid 等)通过厂商面板配置;HEXIS PAD 用作 rover、NTRIP、测量、放样。
Leica, Trimble, Topcon, Sokkia, Spectra, GeoMax, CHC基准站/电台配置封闭 — 需通过其自身软件完成。HEXIS PAD 通过 NMEA 作为 rover 工作。

所有指令在发送前都会显示 — 请对照接收机手册检查(尤其是基准站高度为椭球高还是正高)。

新基准站

  1. ＋ 新基准站 → 在已知点上(选择点)或自主定位「此处」。
  2. 基准站天线高、RTCM 端口、大地水准面差距 N。
  3. 发往基准站的指令… → 检查 → 发送(需 Bluetooth 连接到基准站)。
  4. 设为当前基准站:每个新点都会「关联」到该基准站。

平移基准站

如果基准站架设在自主/错误位置:从列表中打开该基准站 → 输入「所用位置」和「正确位置」→ 应用平移。该基准站的所有点按 dX/dY/dZ 平移,并记录在其备注中。

5. 测量 (Survey)

  1. 点名(自动递增)、编码(最近使用的编码显示为按钮)、天线高(对中杆 + 相位中心)。
  2. 时长:秒(1、2、3、5、10、15、30 s,1 或 3 分钟)或历元;「其他…」可输入任意值。历元 = 接收机的一个定位解(1 Hz 时,1 历元 ≈ 1 s)。对所有历元取平均。仅 FIX:舍弃 FLOAT 历元。
  3. 等待 FIX(设置,默认 10 s):仅当解连续保持 FIX 达到该秒数时才开始测量;按钮显示「⏳ FIX 4/10 s」。
  4. 点保存后,按钮会短暂变为绿色「✓ 点名」(伴随提示音),然后恢复,准备下一次测量。
  5. 声音(设置 → 声音,可调音量和测试):保存点提示音、解变为 FIX 时的上升音、FIX 丢失时的低音和振动。
  6. ● 测量 → 执行质量控制(第 6 节)。测量中再次点击 = 取消。
  7. 带编码的线:相同编码的连续点连接成线(导出到 DXF)。
  8. ⌖ Offset:由距离 + 方位角得到点(手动或来自激光)。
  9. 用已存在的点名测量 → 比较独立测量,并可选择「保存为检核」。

连续测量

主页 → ⟳ 连续测量(或工具栏中的 ⟳ 工具)。选择按距离(例如每 1 m)或按时间(例如每 2 s)、编码、「仅 FIX」和最大 sH。行走时自动保存点,点名自动递增。地图上方显示「⟳ 连续 · N 点」状态条和 ■ 停止 按钮。如果解不是 FIX 或 sH 超过限值,状态条以黄色文字显示原因,且不保存点。

Static

主页 → ◷ Static。输入点、编码、天线高和时长(5 分钟到 2 小时,或「直到我停止」)。接收机保持静止,应用会:

  • 每秒保留一个解,并计算平均值、sH 和 sV。有 FIX 解时只使用 FIX 解。如果完全没有 FIX,该点标记为「无 FIX」。
  • 将接收机的全部数据记录到文件 Documents/HEXIS PAD/Static/<项目>_<点>_<日期>.gnss,用于后处理。如需内业处理,接收机必须输出原始观测值(RTCM3 MSM 或厂商格式)。
  • 结束时显示结果和「分享 / 邮件发送文件」按钮。

运行时再次点 ◷,可查看实时统计并可提前结束。

逐点绘图

在 Survey 中点 ✎ 绘图,在 Draw lines 组中选择 Line(独立直线段)、Polyline(连续线)、Spline(穿过各点的平滑曲线)或 Polygon(闭合多边形)。每个按钮都有表示形状的图标。此后测量的每个点都加入该线 — 地图上方会显示一条绿色状态条,显示类型和点数。可以从最后一个已测点开始。在状态条上:↶ 从线中移除最后一点(点保留),✕ 取消该线(所有点保留),✓ 完成 结束该线。导出 DXF 时,线导出为 LINE / POLYLINE / spline 则为加密 polyline,图层为 HP_<编码>。

天线高 = 杆高 + 接收机偏移

在 Survey 字段中只输入对中杆高度。天线偏移(从天线参考点 ARP 到相位中心,例如 Singular X1 Lite / L1 为 0.068 m)在识别到接收机时自动加上,或在 设置 →「接收机天线偏移」中设置。字段标签显示「对中杆 (+0.068)」,点属性中同时记录两者。

无 GST 时的位置误差

如果接收机不发送 GST(例如通过 Wi-Fi 连接的 Singular),sH/sV 显示带 ~(由 HDOP 和解类型估算:FIX ≈ 1.2 cm × HDOP)。在 QC 检查中计为「警告」而不是拒绝;测量历元的实际离散度照常检查。

在测量中测不可达点

Survey 卡片中 Offset 旁边有 ✕ 不可达 按钮。无需退出测量:

  1. 点 ✕ 不可达。打开 4 点示意图。
  2. 点「● 测量点 1」(或说「采点」)。然后 2、3、4。按钮会自动跳到下一个。
  3. 查看结果、两直线夹角,以及几何图形较弱时的警告。
  4. 点 💾 保存到测量。该点获得测量的下一个编号和当前编码。它会加入线(如果您在测「带编码的线」),编号照常继续。

通过「列表中保留辅助点」选项决定 4 个辅助点保留在列表中还是删除。上方选择中还有其他方法:激光距离 + 方位角、距离交会、直线延长。

用激光测距仪(DISTO 等)从 2–3 个位置测点

用于对中杆无法到达的点:建筑角点、柱子、树、围栏后的井。Survey 卡片中的 ⟟ 激光 按钮。

  1. 以 Bluetooth「键盘模式」连接激光(DISTO 上:Bluetooth → Keyboard mode)并在 Android 中配对。
  2. 站在位置 1,点「● 位置 1:GNSS 测量」(或说「采点」)。
  3. 将激光靠在对中杆上,瞄准该点并在激光上按测量。距离会自动填入字段。如未连接,可手动输入。
  4. 移到几米外的位置 2,使两个位置与该点构成 60°–120° 的夹角。再次进行 GNSS 测量和测距。
  5. 存在两个可能解。选择左 / 右(从位置 1 看向位置 2),或添加第 3 个位置:应用会自动选择并显示残差 (RMS) 供检核。
  6. 💾 保存到测量:该点获得下一个编号和您的编码。

在「距离改正」中可输入例如对中杆半径(如果激光背面靠在对中杆上测量)。高程请选择「各位置平均 Z + dH」。几何图形较弱或距离不「闭合」时,应用会发出警告。COGO → 激光测点 和 不可达点 中也有同样功能。

倾斜 ↔ 严格对中

启用 IMU 时,Survey 卡片中有 ∠ 倾斜 60° 按钮。点击后变为 ⊙ 对中。点击状态栏中的 ∠ 指示,或语音指令「对中」/「倾斜」,效果相同。

  • ∠ 倾斜:对中杆倾斜测量,最大到接收机限值。
  • ⊙ 对中:点仅用垂直对中杆,在对中限差内(例如 ±0.5°)。适用于三角点、检核点和基准站。超出时按钮显示「⏳ 未对中」并等待。
  • 每个点都记录其测量方式和倾斜量。

IMU — 倾斜对中杆测量

如果您的接收机有 IMU,测量时无需整平。补偿在接收机内部完成,应用会确保您不会超出厂商限值测量。

  • 自动识别:应用根据接收机发送的数据自动判断:
    • 如果接收机发送倾斜补偿状态,IMU 立即启用,并告诉您(也会语音播报)允许的最大倾角。
    • 如果只发送倾角(也可能只是电子气泡),会询问一次接收机是否有 IMU,并让您输入规格书中的最大倾斜。如回答「否」,则只保留对中气泡。
    • 如果应用认识该型号(例如 Emlid Reach RS3:60°,CHC i73:45°),使用厂商限值。否则使用 30°,直到您输入规格书中的限值。
    • 所有设置都可在 菜单 → IMU / 对中气泡 中更改。
  • 指示:状态栏显示 ∠ 12°/60°,在限值内为绿色,超出为红色。如显示 ∠ INIT,表示 IMU 需要初始化:按厂商要求摇动对中杆或行走。
  • 保护:超过限值或初始化未完成时,测量不采点。按钮显示「⏳ 倾斜 65° > 60°」并发出警告音。一旦回到限值内,测量自动进行。放样、不可达点和连续测量同样适用。
  • 电子对中气泡:较小,位于坐标旁边,不遮挡测量区域(工具栏常开时,它位于工具栏的「气泡 / IMU」按钮上)。圆点指示对中杆倾斜方向,旁边显示度数。荧光绿 = 垂直,橙色 = 接近,红色 = 超出。点一下在地图上放大显示以精确对中(可拖到任意位置),再点一下隐藏。长按:气泡 / IMU 设置。有 IMU 时,红色虚线圆为接收机的倾斜限值。
  • 无 IMU(带电子气泡的接收机):气泡显示垂直限差,例如「0.4° · ±0.5°」。绿色 = 已对中,橙色 = 接近,红色 = 超出。启用「超出对中限差不采点」选项时,测量会等待直到对中。
  • 气泡始终显示。接收机发送倾斜时,气泡来自接收机,无需任何校准。否则,如果手机或平板固定在对中杆支架上,气泡来自手机传感器,并显示「手机」标识。
  • 手机校准 — 自动,仅在需要时:如果接收机不发送倾斜且手机尚未校准,会自动出现提示:保持杆尖不动,将对中杆前后、左右摇动几度,约 10 秒。进度条填满后气泡自动完成校准,无需水准器,也无需按按钮。只有手机在支架上的位置改变时才需重做:在气泡显示「校准」时点击它,或从气泡设置中进行。
  • 自定义限值:可设置比厂商更小的限值,例如 30°,以获得更高精度。
  • 高度:当接收机输出杆尖位置时,杆高在接收机中设置,应用不会再次扣除。该选项默认启用。
  • 记录:每个点都记录测量中的最大倾斜和接收机型号。
  • 当接收机发送倾角时,应用会进行检查(PASHR、PSAT HPR、PTNL AVR、HPD 消息或 Unicore 倾斜状态)。如果接收机不发送倾角,则显示「∠ IMU」,需由您自己遵守厂商限值。
  • 作业前,用倾斜对中杆测量一个已知点。以此确认杆高和初始化。

浮动测量按钮

地图上有一个圆形按钮 ● 测量。放样时变为紫色并显示记录。

  • 点击 = 测量,与大按钮完全相同。测量中变为橙色 (■),点保存后变为绿色 (✓)。
  • 拖动 = 移到顺手的位置,并记住该位置。拖动时不会触发测量。
  • 设置 → 浮动测量按钮:「✋ 左手」/「右手 ✋」将其移到对应一侧。有「大按钮」选项便于戴手套使用,也可以将其停用。
  • 如果 Survey 或 Stakeout 卡片在其下方打开,按钮会自动移到卡片上方。

来电和后台运行

只要接收机已连接或 NTRIP、static 正在运行,应用就会以高优先级在后台继续工作。来电、打开其他应用或屏幕熄灭时,都不会中断:

  • 与接收机的连接、NTRIP 改正、连续测量和 static 记录照常继续。
  • 通知栏显示「HEXIS PAD — 接收机已连接 · NTRIP」。点击即可返回应用。首次使用时 Android 会请求通知权限:点允许。
  • 通话期间应用不会语音播报(语音确认),语音指令的麦克风也会关闭,直到您返回。
  • 如果通话期间 Bluetooth 断开,也会在后台自动重连。
  • 断开接收机并停止 NTRIP 后,通知会消失。

在某些手机上(Xiaomi、Huawei、开启「省电」的 Samsung),请在 Android 电池设置中将 HEXIS PAD 设为「无限制」。

语音指令

🎙 语音 工具,或 主页 → 语音指令,或 设置 → 语音指令。监听时,地图上方显示绿色指示「🎙 正在听…」。点击它即可关闭。

  • 「采点」(或「测量」、「记录」):测量点。放样时记录 Pn。
  • 「删除」:删除最后测量的点。下一个编号会重新使用该点名。
  • 「撤销」:在 15 s 内恢复被删除的点。屏幕上也有黄色的「↶ 撤销」按钮。
  • 「下一个」/「上一个」:放样点。
  • 「取消」/「停止」:停止测量或连续测量。

应用会语音确认(「已保存 P12」)。首次使用时会请求麦克风权限。识别由手机的语音服务完成。如果已下载中文离线语音包(Android 设置 → 语音识别),无网络时也能使用。⌫ 删除最后一个 工具一键实现与「删除」相同的功能。

7. 放样 (Stakeout)

点

从列表选择目标,用 ◀ ▶(下一个/上一个),或在地图上用 ⌖ 选取(点、DXF/DWG 顶点)。目标圆在远处时显示箭头,靠近时显示带刻度的同心圆。绿色 = 在限差内,伴随提示音和振动。

方向参考:「参考:移动」(前/后、右/左,相对于行走方向)、「参考:北」(dX/dY),或「参考:点」(朝向某点定向,例如面向一根桩)。挖方 / 填方 = 设计 Z − 地面。

线

图纸多段线(含圆弧)、两点或已测线。桩号留空 = 实时里程和垂距。输入桩号 + Offset = 目标;▶ 按「步长」前进。

面(地面、坡度)

在 COGO → 地面坡度 中:参考点 + 主坡度/横坡 %、由 3 点确定的平面,或水平面。实时显示设计 Z 和挖方/填方。

直角定位

基线 A→B:自 A 起的桩号和垂距(+右)。生成矩形的 4 个角点及检核对角线。

⛶ 大字体全屏放样。● 记录:测量并保存已放样点,点名为目标名加「n」(例如 P1 → P1n),附带相对目标的 dX/dY/dZ,无需退出放样;之后自动跳到下一点。📄 放样确认文件:CSV 和 TXT,包含目标、已放样点、偏差以及在/超出限差标识 — 可保存、分享或邮件发送。限差:设置。

由多边形一条边生成格网(植树、桩位)

COGO → ⁘ 格网,或工具栏中的 ⁘ 工具。

  1. 多边形:一条已测线(例如用编码「边界」测得的边界)、DXF/DWG 图纸中的闭合多段线,或按顺序选取的顶点。
  2. 基准边:各行与之平行(offset)。默认为最长边,在地图上显示为红色。
  3. 间距:行内间距(例如 5 m)和行距(例如 5 m)。还可设置第 1 行到基准边的 offset,以及到所有边界的最小距离。
  4. 图案:方形或菱形(交错,每隔一行偏移半个步长)。启用「居中」选项时,每行左右边距相等。
  5. 地图上实时显示预览(绿色点),同时显示点数和行数。
  6. ✓ 生成放样点:点名为 T1、T2…,编码为「树」,均可修改。编号为蛇形(往返),使「下一个」始终带您到相邻的点。放样立即从 T1 开始。

Relocalize — 将点平移到已知点

适用于在错误 FIX 或错误基准站下测量、整体发生偏移的点。计算 → Relocalize(或 ⇄ 工具)。

  1. 哪些点要移动:全部、某一天测量的点,或从点 A 到点 B。已知点和三角点永远不会改变。
  2. 已知点:「＋ 添加已知点」→ 选择位置错误的实测点。然后输入其正确坐标,可从列表中的已知点选取或手动输入。
  3. 1 个已知点:仅平移 dX、dY、dZ。2 个:平移和旋转。3 个或更多:还可检查残差 (RMS),并可选计算比例。
  4. 查看 dX、dY、dZ、旋转和残差,然后点应用。所有点移到正确位置,每个点的备注中记录该改正。
  5. ↶ 撤销上次 relocalize:点恢复到原来的位置。保留最近 10 次改正。

9. 坐标系

GGRS87 — HEPOS 官方模型(默认):希腊地籍的 HTRS07 → GGRS87 转换(7 参数 + 2 km 的 dE/dN 改正格网,双线性内插),已内置于应用中 — 无需任何文件。已用希腊地籍官方算例验证,偏差小于 1 mm。请在使用 HEPOS 和提供 ETRS89 的网络时使用。Kastellorizo 岛使用其专用模型(3 个平移量,TM87,L0 = 27°)。

「GGRS87 — 3 参数」(EPSG:2100) 为近似转换:不使用格网时,平均偏差约 0.6 m,部分地区超过 2 m。高程:希腊地籍尚未随 HEPOS 提供官方大地水准面 — 正高来自接收机的模型;如需厘米级精度,请在 2–3 个已知高程点上进行局部校正。

其他国家:应用会根据您的位置自动选择坐标系和大地水准面 — 参见境外作业。您也可以为任何国家输入自定义 proj4。高程:接收机正高或椭球高。局部控制网:COGO → 局部校正。

11. 文件和邮件

导入

来自邮件:点击附件 →「打开方式」→ HEXIS PAD。导入向导直接打开。如已下载:导入 →「选择文件」。窗口直接打开下载文件夹。

只有一个「选择文件」按钮 — 自动识别文件类型:

  • TXT, CSV, XYZ, PNT, DAT:任意分隔符(逗号、分号、tab、空格),小数逗号或小数点,希腊语编码。
  • XLS, XLSX, ODS:选择工作表。
  • DXF, DWG:底图图纸,可选 dX/dY 平移,并可将 POINT 导入为放样点。
  • KML, GeoJSON:B, L 坐标的点 → 转换到项目坐标系。
  • 粘贴:来自邮件、Excel、消息的文本。

导入前可查看预览:列表格(自动识别 点名 / X / Y / Z / 编码 — 如需可更改)、是否有标题行、X↔Y 交换、B/L、点的小示意图、检查点是否落在正确区域,以及重复点名的处理(重命名 / 跳过 / 替换)。

来自其他应用(Gmail、文件、Drive、Viber):打开方式 或 分享 → HEXIS PAD。在使用浏览器的平板上:将文件拖到地图上。

导出

快速选项:仅点 (TXT)、DXF(点 + 线) 或 全部;也可逐个勾选格式。点在内部以完整精度保存;导出时坐标写为 4 位小数(0.1 mm)— 可在 设置 →「导出坐标小数位」中改为 3 或 5。

TXT、完整 CSV(精度、QC、基准站、放样偏差、照片)、DXF(点/点名/高程/编码分图层、线)、KML、GeoJSON、照片 — 全部打包为 ZIP。💾 保存(文档/HEXIS PAD)、↗ 分享 或 ✉ 邮件(打开邮件应用并附上文件)。

TXT 中的基准站：勾选「+ 每个点附基站 ID」（默认开启）后，TXT 每一行末尾会写入测量该点所用基准站的 ID，例如 P12,214295.537,4302900.046,62.345,树,HxGN_SmartNet/LEFK_RTCM3/2417（网络 / mountpoint / 基站编号）。文件末尾以 # 开头的行中写有基准站表：ID、网络、mountpoint、基站编号、项目坐标系中的基准站坐标、椭球高、B/L、ECEF、天线高，以及每个基准站测量了哪些点。如果读取 TXT 的程序只接受 点名,X,Y,Z,编码，取消勾选该选项即可。CSV 始终包含 BaseID、BaseX、BaseY 列。

每次导出都含照片:无论选择哪个快速选项(「仅点」、「DXF」、「全部」),点的照片都始终一起导出。它们放在 ZIP 文件的 photos/ 文件夹中,每张照片以点名命名。放样文件(CSV + TXT + 照片)同样如此。如某次发送不需要照片,取消勾选「点的照片」即可。

电池和电源

  • 屏幕常亮「工作时」(默认):当接收机已连接且最近 10 分钟内触摸过屏幕,或正在放样、连续测量或 static 时,屏幕保持常亮。否则正常熄屏,与接收机的连接和 NTRIP 在后台继续。轻触即可点亮,回到原来的位置。
  • 地图只在可见内容变化时重绘:您移动或解改变时。静止不动时,处理量降到约 1/4。
  • 节能:未充电且电量低于 30% 时自动启用。此时地图和指示每秒刷新 2 次,无触摸 3 分钟后熄屏(而不是 10 分钟)。
  • 气泡永远不受影响:始终实时显示。
  • 所有设置在 设置 → 电源 中:「屏幕常亮」(工作时 / 始终 / 跟随手机设置)和「节能」(自动 / 始终 / 从不)。
  • 提示:屏幕亮度是最大的耗电项。阳光下需要调高,但在阴影中或夜间请在手机上调低。

许可证

  • 代码会绑定到首次输入它的设备。在其他设备上无效。如更换手机,请申请解绑。
  • 按使用时长计费的许可证(例如 7 或 10 小时野外作业):仅统计应用在屏幕上打开的时间 — 屏幕熄灭或退出应用时停止计时。在用完前 30′ 和 10′ 发出提醒。时长在「许可证」中显示的日期前有效。
  • 按天计的试用许可证:天数从激活时起算。
  • 两种许可证在野外都可无网络正常使用;联网时再上传使用时间。有网络时会自动检查许可证;如果设备超过 7 天完全没有联网(所有者设备为 30 天),会要求进行一次简短检查:打开移动数据并点激活。

12. 照片

在 Survey 中点 📷(最后一个点)、在放样中(最后一个已放样点)或在点详情中拍照。每张照片都带有水印,包含点名、编码、坐标、日期和解状态,并以点名导出。

保存位置:每张照片保存在项目中,与其点关联。可从点详情打开,并通过 导出 → 照片 (ZIP) / 邮件 导出。此外还会自动在手机中保存副本,位于 文档/HEXIS PAD/照片/<项目>/ 文件夹,以点名命名,即使卸载应用也不会丢失。可在 设置 →「每张照片在手机中保存副本」中关闭。

放样中的记录:到达点位后,点 ● 记录。它会作为新点测量,例如「3n」,附带相对目标的 dX / dY / dZ 偏差,并写入放样文件。
